# 文書の決まり

- README は英語が主で、`README.ja.md` を付ける。それ以外の文書は日本語
- 日本語の文は常体で書き、見出しは言い切りか体言止めにする。太字とダッシュを多用しない。「項目名: 説明」の並べ方をせず、文で書くか見出しで分ける
- 日付は「2026年11月3日」と書く。コマンドやファイル名の中の日付はそのまま
- 数字には出典か、測った方法と日時を付ける。確かめていないことは未確認と書く
- 母や家族の名前、住所、電話番号、メール、実際の相談の中身を書かない。「母」「妹」「作者」と書く
- リポジトリの中のファイルを指すときはリンクにし、リンクの文字はバッククォートで囲む
