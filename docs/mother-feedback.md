# 母の利用の記録

母が実際に使って止まったところ、どう直したか、直したあと手助けなしでできたかを、日付つきで残す。2026年11月7日まで書き足し、[`README.md`](../README.md) の「母の利用から直したこと」と、デモ動画で何を見せるかはここから選ぶ([`docs/plan.md`](plan.md) のタスク6、タスク10、タスク16)。

## 書き方

1回の場面ごとに、日付と場面の名前を見出しにする(「### 2026年11月6日 初回の設定」のように)。本文には、何を試したか、母がどこで止まったか、そのときどうしたか、どう直したか(直した Issue や PR の番号)、直したあと母が手助けなしでできたかを文で書く。まだ直していないときは、直す先の Issue の番号を書いておき、直したあとに同じ場面の続きとして書き足す。

人は「母」「妹」「作者」と書く。名前、住所、電話番号、メール、端末の名前を書かない。相談や届いたメッセージ(SMS、メール、ページ)の中身、母が話した言葉そのものは書かず、「警察を名乗る電話のことを話した」のように何の話かだけを書く。

貼る画像は、本番の家族に入っていない端末で撮った画面だけにする。母の見本用のシミュレータ「mimamori mother」や体験モードの画面はよい。母や家族の実機の写真と、本番の家族に入っている家族役のシミュレータ「mimamori iPhone」の画面は貼らない([`docs/harness.md`](harness.md) の「設定の範囲」、`/mm-screen-guide` と同じ線)。本番の家族の画面には、笑顔の写真(母や家族の顔)、カードや通知に出る家族の名前、実際の相談の1行、実際に届いた文面、設定の画面の Apple ID が映りうる。コミットの前の関門は文字の行しか見ず、画像は通る。笑顔の写真は Claude にも渡さない決まりなので、貼るために実機の写真を Claude に読ませて映り込みを確かめることもしない。実機で見たことは文で書く。

タスク10の2つの観察、誘導なしで相談できるか(#46)と、母、妹、作者で試した結果もここに書く。少人数の観察なので、何人で何回試したかを書き、効果を言い切らない。模擬の電話をかけるときは、先に母の同意をもらったことも書く。使うことへの同意と、動画に映すことへの同意は別にもらう([`docs/design.md`](design.md) の「データの扱い」)。#48 や #31 のような実機の はい/いいえ の確かめは、その Issue のコメントに文で残す。Issue も提出のときに公開されるので、実機のスクショは Issue にも貼らない。違ったところは文で書き、画面を見せたいときは会話で Claude に渡す(笑顔の写真が映る画面は渡さない)。ここには、そのとき母や妹が止まったり迷ったりしたことがあれば書く。

数字には測り方と日時を付ける。確かめていないことは未確認と書く。

### 2026年11月7日 誘導なしの初めての相談

母の iPhone にビルド12を入れ、作者が招待のコードを渡して家族に入ってもらった(家族の側は作者の iPhone)。そのあとは作者が案内せず、母が自分で使った(#46)。試したのは母1人で、この日の1回の場面だ。

母は、iPhone の容量の画面のスクショを自分で送り、丸の付いた案内で進めた。Gmail の許可も自分で出した(母の画面の「Gmail」のボタンが消えた)。ここで止まったところは無かった。

母はアプリの使い方を2回相談した。何のアプリか、母が何と言ったかは書かない。母は、みまもりを ChatGPT のように使えると思ったと作者に話した。1回目は、AI がそのアプリを知らず、答えきれない相談として家族に回り、「これは家族と一緒にやろう。家族に伝えました」が返った。母の画面の上には「家族から返事がまだ」の帯が残った。この日に母が止まったのはここだった。2回目は、母が言葉を足すと AI が手順を答えたが、AI がその画面を見たことがあるとは考えにくく、ボタンや欄の名前を推測で書いた可能性がある(確かめていない)。

同じ日に #251(PR #252、PR #254、PR #255)で答え方を直し、本番に出した。知らないアプリや見ていない画面は家族に回さず「その画面を写真で見せてね」と聞き返す。スマホ以外の質問(料理、天気、調べもの)にも答える。家族に回すのは、AI が案内したあとも母が同じ話題で困っているときと、お金、認証コードや暗証番号、構成プロファイル、初期化と全部の消去、詐欺の疑いのときにした。裏側だけの直しなので、母の iPhone のアプリを更新しなくても変わる。母役のシミュレータから本番に送ると、知らないアプリの使い方には写真を求める1行が返り、家族には知らせが行かなかった(#251 のコメント)。

直したあと、母が手助けなしで同じような相談をできたかは、まだ見ていない。母の iPhone で確かめることは #187 で作者に頼んだ。試験用のニセ警察の電話(#46 の本題)は、2026年11月8日の撮影と一緒に行う。
