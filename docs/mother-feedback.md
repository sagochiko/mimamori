# 母の利用の記録

母が実際に使って止まったところ、どう直したか、直したあと手助けなしでできたかを、日付つきで残す。11月7日まで書き足し、README の「母の利用から直したこと」と、デモ動画で何を見せるかはここから選ぶ([`docs/plan.md`](plan.md) のタスク6、タスク10、タスク16)。

## 書き方

1回の場面ごとに、日付と場面の名前を見出しにする(「### 2026年11月6日 初回の設定」のように)。本文には、何を試したか、母がどこで止まったか、そのときどうしたか、どう直したか(直した Issue や PR の番号)、直したあと母が手助けなしでできたかを文で書く。まだ直していないときは、直す先の Issue の番号を書いておき、直したあとに同じ場面の続きとして書き足す。

人は「母」「妹」「作者」と書く。名前、住所、電話番号、メール、端末の名前を書かない。相談や SMS の中身、母が話した言葉そのものは書かず、「警察を名乗る電話のことを話した」のように何の話かだけを書く。画面の写真を貼るときは、通知や連絡先に個人の情報が映っていないかを確かめてから貼る。

タスク10の2つの観察、誘導なしで相談できるか(#46)と、母、妹、作者で試した結果もここに書く。少人数の観察なので、何人で何回試したかを書き、効果を言い切らない。模擬の電話をかけるときは、先に母の同意をもらったことも書く。使うことへの同意と、動画に映すことへの同意は別にもらう([`docs/design.md`](design.md) の「データの扱い」)。

数字には測り方と日時を付ける。確かめていないことは未確認と書く。
