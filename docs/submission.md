## 作品の要約

みまもりは、離れて住む高齢の母の iPhone を、母が何もしなくても詐欺から守り、スマホの困りごとには話しかけて相談でき、毎朝の笑顔で家族とつなぐ iOS アプリだ。裏側は Cloudflare Workers で動く。テーマは2つ目の「本来、誰にでも届くべきものを」にした。詳しい家族が近くにいる人だけが詐欺から守られている、という壁をなくしたい。

主役はニセ警察詐欺の場面だ。警察庁の確定値では、2025年の特殊詐欺の被害額1,423.1億円のうち、ニセ警察詐欺が1,005.0億円を占めた([警察庁](https://www.npa.go.jp/bureau/safetylife/sos47/new-topics/260605/01.html)。割ると約70.6%)。iPhone のアプリは通話も LINE も見られず、犯人は「誰にも話すな」と言う。そこで、3分以上の通話がアプリを開いたまま終わると、アプリのほうから「さっきの電話、大丈夫だった？」と聞く。母がそのまま話すと、裏側の規則が筋書きを見抜いて1段階で「電話を切って」と返し、家族全員の iPhone に、何の相談でどれだけ危ないかのカードが届く。母と話した家族が「解決」を押すと、ほかの家族にもそれが伝わる。

母が何もしなくても見るのは、知らない相手からの SMS(Message Filter の拡張)、Gmail、Safari で開いたページだ。危なさは3段階で、どの経路でも「安全です」とは言わない。SMS や本文の中の「家族には知らせないで」のような文には従わず、詐欺の印として段階を上げる。家族のカードには母の言葉や届いた文を写さない。

dev の114件の例文で、規則だけの見逃しは60件中6件(10.0%、2026年11月7日)、規則と Claude の組では60件中1件(1.7%)、本物を家族に回した誤報は54件中4件(7.4%)だった(2026年11月7日、本番と同じ関門で測った回。[`eval/RESULTS.md`](../eval/RESULTS.md) のその日の `rules+claude` の行)。Claude は規則が見逃した声の相談4件を拾い、相談の見逃しは32件中0件になった。残る1件は、今の関門で Claude に渡さないページの例文だ。誤報の4件はどれも送金や認証コードのような AI が案内しない話題の相談で、Claude の答えにかかわらず家族に回す決まりのため、母には詐欺の警告ではなく「これは家族と一緒にやろう」と返る。中央値は1622ミリ秒だった。測り方は [`eval/README.md`](../eval/README.md) にある。審査員は「体験」から、家族を作らずに1台で母の画面と家族のカードを見られる作りにした。シミュレータでは確かめたが、TestFlight の版で「体験」が出るかは、2026年11月7日の時点でまだ確かめ待ちだ(#187)。

## 使った Claude の製品

作品の中では Claude API と Claude Managed Agents を使い、開発は Claude Code で進めた。モデル ID は2026年11月7日に Claude の公式ドキュメント([Haiku 5.5](https://platform.claude.com/docs/en/models/haiku-5-5/overview)、[Sonnet 5.5](https://platform.claude.com/docs/en/models/sonnet-5-5/overview))で確かめた。

### Claude API

SMS、メール、ページの判定は Claude Haiku 5.5(`claude-haiku-5-5`)に Structured Outputs で頼む([`server/src/claude.ts`](../server/src/claude.ts))。答えは段階、理由、母への1行の決まった形で、中の文が誰に知らせるかを変えられない。即答は規則が返し、Claude の判定は Cloudflare Queues で後から重ねる。

母との会話と、母が共有したスクショや書類の読み取りは Claude Sonnet 5.5(`claude-sonnet-5-5`)にした([`server/src/consult-judge.ts`](../server/src/consult-judge.ts))。母は画面の前で待っているので、裏側は最大15秒待ち、間に合わなければ規則だけで答える。設定の画面のスクショには、押す場所に丸を付けて返す。

### Claude Managed Agents

SMS、メール、ページで1段階か2段階の知らせが出たあと、急がない裏の調べものに使う([`server/src/agents.ts`](../server/src/agents.ts))。モデルは `claude-sonnet-5-5`、ベータの見出しは `managed-agents-2026-04-01` で、道具は `web_search` と `web_fetch` だけにし、開けるのは公式の20のサイトに絞った。家族のカードに足すのは、エージェントが挙げた公式のページのサイトから決めた1行(「<表示名>の注意喚起」)だけで、エージェントの書いた文は家族にも D1 にも出さない。2026年11月7日の時点では、本番でこの調べものが根拠を書いた記録はまだ無い。

### Claude Code

アプリ、拡張機能、裏側、試験のすべてを Claude Code で書いた。1件の Issue ごとに、実装役(`mm-implementer`)、検証役(`mm-verifier`)、レビュー役(`mm-reviewer`)を別のサブエージェントにし、レビューの結果を PR に残してからマージした。役のモデルは途中で変えた。2026年11月4日から6日までは、レビュー役、監査役、採点役と、作者がいないあいだの autopilot の主を Fable で動かし、2026年11月6日に作者の判断でこれらを Opus に戻した。それ以降、Fable を使うのは advisor だけで、シミュレータの画面を見ない確かめ(`make verify`、試験、grep)の検証役には Sonnet も使った([`CLAUDE.md`](../CLAUDE.md) の「モデルの使い分け」、[`docs/dev-log.md`](dev-log.md) の2026年11月5日と6日の記録)。ハッカソンのルールと母のデータを守る決まりはフックで止めている(期間の前のコードを開く、holdout を読む、秘密を読む、レビューの無い PR をマージする、など)。仕組みは [`docs/harness.md`](harness.md) にある。

フックの記録では、2026年11月3日から7日までに、レビュー役を170回起動して21回再開し、実装役を76回、検証役を61回起動した。フックが止めたか作者の確認に回した操作は208回だった([`docs/claude-usage.md`](claude-usage.md))。`origin/main` には857のコミットがあり、マージを除く662のうち625に `Co-Authored-By: Claude` が付いている。マージした PR は107件、Issue は99件(閉じたもの67件)、レビュー役の報告の原文は [`docs/audits/raw/`](audits/raw/) に194件ある。

## 一番詰まった場面

[`docs/dev-log.md`](dev-log.md) の2026年11月4日の記録「マイクを初めて押すと落ち、主役の一言は2段階だった (#57)」から取った。順番は記録のまま、時刻だけを外し、記録の後に分かったことを最後の段落に足した。

声の相談を作者の iPhone で初めて確かめていた(#57)。作者の iPhone を母の役、シミュレータを家族の役にし、アプリを消して入れ直して、許可を一度も聞かれていない状態から始めた。

作者がマイクを押したあと、Claude Code に「あれ、iPhoneのログみてくれますか」と頼んだ。

音声認識の許可に答えた直後にアプリが落ちていた。`xcrun devicectl device copy from --domain-type systemCrashLogs` で取り出した落ちた記録の要所は `EXC_BREAKPOINT`、`closure #1 in closure #1 in static VoiceListener.permitted()`、`TCC __TCCAccessRequest_block_invoke_8` だった。直した版を入れ直すと、相談が本番の裏側に届いてから約1秒で家族の役のシミュレータに通知が届いた。ただ、「警察から電話があって、口座が犯罪に使われてるって」の段階は1ではなく2で、答えに「いったん電話を切って」が無かった。

落ちたのは、`@MainActor` の `VoiceListener` の中の閉包を TCC が裏のキューから呼び、Swift 6 の実行時のチェックが止めたためだった。同じファイルのほかの閉包は同じ理由で切り離してあり、ここだけ漏れていた。主役の一言は設計で1段階と決めていたのに、筋書きの規則の部品に「警察から電話」が無かった。試験(eval)は相談の例文も SMS と同じ規則に通していたので、dev の数字にも出ていなかった。

落ちた方は `permitted()` を `nonisolated` にし、閉包を `@Sendable` にして直し(PR #71)、入れ直して同じ流れを通した。2段階の方は、相談の筋書きの数え方にだけ「警察を名乗る相手からの連絡」を部品として足した(#72)。SMS とページの規則にも足す案は、銀行や警察の本物の注意喚起が「警察を名乗る電話」と「口座が犯罪に使われている」を並べて書くので採らなかった。eval が相談の道を測っていないことは #74 にし、今は相談を本番の道で測っている。直したあと、作者が自分の iPhone で1段階と決まった答えを確かめた(#77)。使ったのは `/mm-device`、`xcrun devicectl`、MobileBuildMCP でのシミュレータの操作、mm-reviewer(SIL に落として実行時のチェックの数を数えた)、mm-implementer。

## 感想と改善の案

1人で6日のあいだに、iOS の拡張機能4つ(うち Call Directory は中身の無い作り)と裏側と試験までを作れたのは、実装、検証、レビューを別のサブエージェントに分けたからだと思う。書いた本人と別の文脈のレビュー役が、こちらの思い込みを何度も崩した。上の場面のように、実機で落ちた記録を読んで原因まで切り分けるところも Claude Code に任せられた。一方で、母が実際に使ったときの記録は、2026年11月7日の時点ではまだ [`docs/mother-feedback.md`](mother-feedback.md) に入っていない。主役を実機の2台で通す確かめ(#48、#31)も作者の手を待っている。作るのは任せられても、本物の使い手の手と時間だけは前倒しできなかった。

改善の案は1つ。自由な文を語の一覧でふるう直し方に、早めに見切りをつける仕組みがほしい。「安全です」と伝えないための網は、#51、#53、#183 で、レビューのたびに抜ける言い換えが見つかり、そのたびに語を足していた。#183 では4回のレビューを経て、エージェントの文を家族に出すのをやめ、公式のサイトの URL だけを受け取る作りに変えた([`docs/dev-log.md`](dev-log.md) の2026年11月6日と7日の記録)。同じ種類の直しが2回続いたら、語を足すのではなく、自由な文を出さない作りに替えられないかを先に問う。これを Claude Code の skill かレビュー役の確かめの項目にしておけば、締切前の時間をもっと主役に回せたはずだ。
