このプロジェクトは、離れて暮らす高齢の親が詐欺に一人で向き合うしかない状況を、親が何もしなくても家族が代わりに気づいて電話できる形に変える iOS アプリです。警察を名乗る電話で「口座が犯罪に使われた。誰にも言うな」と言われた母がいるとする。アプリは通話を聞けないので、3分以上の電話がアプリを開いたまま終わると「知らない人や勧誘の電話で困ったら教えてね」と声をかける。母がそのまま話すと、裏側の規則がニセ警察の筋書きを見抜いてすぐに答え、電話を切ってお金を動かす前に家族に確かめるよう伝える。家族全員の iPhone には、危なさの段階と何の相談かのカードが届く。家族の誰かが母に電話して「解決」を押すと、ほかの家族にも伝わる。Gmail と Safari で開いたページは、母が何もしなくても見張る。知らない相手からの SMS の拡張も作ったが、実機ではまだ確かめられていない。危なさは3段階で、どの経路でも「安全です」とは返さない。スマホの使い方や天気のような質問には AI が答え、案内のあとも困っていれば家族に回す。毎朝の笑顔の写真で、何も無い日も家族とつながる。

## 使った Claude の製品

フォームはチェックで選ぶ形で、選択肢は Claude Code CLI、Claude Code IDE 拡張、Claude Code Desktop、Cowork、Claude.ai、Claude API、Managed Agents、Agent SDK、その他。付けるのは Claude Code CLI、Claude.ai、Claude API、Managed Agents、その他の5つで、その他は Claude in Chrome にあたる(2026年11月8日にフォームの画面で確かめた)。

- Claude Code。アプリ、拡張機能、裏側、試験のすべてを書いた
- Claude API。SMS、メール、ページの判定と、母との会話、スクショの読み取り、ウェブ検索に使う
- Managed Agents。知らせのあとに公式のサイトで注意喚起を探す裏の調べものに使う
- Claude in Chrome。TestFlight の配布と App Store Connect の画面の操作に使った
- claude.ai の Artifacts。作者向けのページを作るのに使った

作品の中で Claude API と Claude Managed Agents を使い、開発は Claude Code で進めた。モデル ID は2026年11月7日に Claude の公式ドキュメント([Haiku 5.5](https://platform.claude.com/docs/en/models/haiku-5-5/overview)、[Sonnet 5.5](https://platform.claude.com/docs/en/models/sonnet-5-5/overview))で確かめた。

### Claude API

SMS、メール、ページの判定は Claude Haiku 5.5(`claude-haiku-5-5`)に Structured Outputs で頼む([`server/src/claude.ts`](../server/src/claude.ts))。答えは段階、理由、母への1行の決まった形で、中の文が誰に知らせるかを変えられない。即答は規則が返し、Claude の判定は Cloudflare Queues で後から重ねる。2026年11月8日からは、Gmail で2段階になったメールの一部を、同じキューの中で Sonnet 5.5 のウェブ検索で公式のドメインと照らし、条件を満たすときだけ3段階に下げる([`server/src/mail-official.ts`](../server/src/mail-official.ts)、PR #277)。

母との会話と、母が共有から送ったり、チャットの写真のボタンで選んだりしたスクショや書類の読み取りは Claude Sonnet 5.5(`claude-sonnet-5-5`)にした([`server/src/consult-judge.ts`](../server/src/consult-judge.ts))。写真のボタンはビルド14に入っていて、実機で確かめた記録はまだ無い(#187)。母は画面の前で待っているので、裏側は最大15秒待ち、間に合わなければ規則だけで答える。設定の画面のスクショには、押す場所に丸を付けて返す。

天気やお店の営業時間のような今の情報が要る質問は、ウェブ検索のツールで調べて答える(#251)。構造化出力は出典(citations)と一緒に使うとエラーになり、ウェブ検索は出典が必ず付くので([Structured outputs](https://platform.claude.com/docs/en/build-with-claude/structured-outputs)、[Web search tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool))、2回に分けた。1回目はいつもの構造化の判定で、検索する言葉も書かせる。2回目は構造化なしの Sonnet 5.5 にウェブ検索を付けて答えさせる。15秒の締切は2回の合計に当て、残りが6秒を切れば2回目を呼ばず、2回目が失敗したり網に当たったりしたら1回目の答えを返す。答えの終わりには出典を1つ付ける。サイト名を読むのは公的なサイト(`.go.jp` など)とよく知られたサイトだけで、ほかは「(ウェブで調べた結果)」にする。検索の上位に来た偽のサイトを、見に行く先として母に聞かせないためだ。2026年11月7日に本番で天気の質問を送ると、約7秒で「(weathernews.jp より)」の付いた答えが返り、家族には知らせなかった(#251 のコメント)。

### Claude Managed Agents

SMS、メール、ページで1段階か2段階の知らせが出たあと、急がない裏の調べものに使う([`server/src/agents.ts`](../server/src/agents.ts))。モデルは `claude-sonnet-5-5`、ベータの見出しは `managed-agents-2026-04-01` で、道具は `web_search` と `web_fetch` だけにし、開けるのは公式の20のサイトに絞った。家族のカードに足すのは、エージェントが挙げた公式のページのサイトから決めた1行(「<表示名>の注意喚起」)だけで、エージェントの書いた文は家族にも D1 にも出さない。2026年11月7日に本番で1回動いた。作者が Safari で試しのページを開くと、数分後、本番の D1 の知らせ2件に警察庁、国民生活センター、情報処理推進機構の注意喚起の3件が根拠として書かれていた(#187 のコメント)。家族のカードの1行は見ていない。

フックの記録では、2026年11月3日から8日までに、レビュー役を249回起動して21回再開し、実装役を110回、検証役を86回起動した。フックが止めたか作者の確認に回した操作は300回だった([`docs/claude-usage.md`](claude-usage.md) のフックの表の合計から、許した記録と通した記録の56件を除いた数。表は `make usage` で作り直せ、56件は `.claude/logs/usage.jsonl` の `detail` の頭の語で分けて数えた)。`origin/main` の `c9366d0` には1,263のコミットがあり、マージを除く977のうち936に `Co-Authored-By: Claude` が付いている。マージした PR は167件、Issue は118件(閉じたもの106件)、レビュー役の報告の原文は [`docs/audits/raw/`](audits/raw/) に298件ある(`git ls-tree --name-only c9366d0 docs/audits/raw/ | grep -c mm-reviewer`)。コミットの数は `git rev-list --count --no-merges --grep='^Co-Authored-By: Claude' c9366d0` のように `c9366d0` を付けて数え、PR と Issue の数は `gh pr list --state merged --limit 500 --json number --jq length` などで2026年11月8日に数えた値だ。コマンドの一覧は [`README.md`](../README.md) の「Built during the hackathon」にある。

### 何が起きたか、期待との違い

### どう対処したか

止まる方は、まず PR #150 で Stop フック(`keep-going.sh`)を足した。worktree が残っている、main 以外のブランチにいる、最後の応答に残りの一覧の語がある、のどれかで応答を終えようとしたら、続けさせる。作者待ちの応答と、作者を待つ裏のループがあるときは通す。同じ残りには1回だけ、1セッションで3回までにした。試験を21本足し、3回のレビューを通した。ただ、フックが捕まえるのは残りの一覧を並べて終える形だけで、その夜の「今夜はここで止めます」は通ってしまった。そこで、止める前に開いている Issue を全部見て、作者の要らないものが残っていれば次のマイルストーンにも進むことと、作者に聞くのは本当に要るときだけにすることを、Claude Code のメモリに足した。

倒しすぎた方は、#251(PR #252、#254、#255)で答え方を変えた。知らないアプリや見ていない画面は家族に回さず「その画面を写真で見せてね」と聞き返す。スマホ以外の質問(料理、天気、調べもの)にも答え、今の情報が要る質問はウェブ検索で答える。家族に回すのは、案内のあとも母が同じ話題で困っているときと、お金、認証コードや暗証番号、初期化、詐欺の疑いのときにした。母役のシミュレータから本番に送ると、天気の質問が最初は試しの家族に回った。1回目の Claude が検索する言葉だけを書いて答えを空にし、それを裏側が捨てていたためで、PR #254 で直したあとは約7秒で出典つきの答えが返り、家族には知らせなかった。使ったのは Claude Code の Stop フック、mm-implementer、mm-reviewer、母役のシミュレータ。

## 公式の情報は十分に見つかったか

おおむね見つかった。Claude API のモデル ID、Structured Outputs の形、ウェブ検索のツールの料金と形は、`claude-docs` の MCP で公式の文書を引いて確かめてから書いた。構造化出力と出典を一緒に使えないことも、Structured outputs の文書の Feature compatibility で見つけ、ウェブ検索を2回の呼び出しに分けた。

見つからなかったものは2つある。アプリが止まっているあいだに通話の終わりを知れるかは、Apple の文書では決めきれず、Apple の DTS に聞いて、できないと答えをもらった([`docs/design.md`](design.md))。メールの判定で Claude を何秒まで待つかを決められる文書も無かった([`docs/dev-log.md`](dev-log.md) の2026年11月7日の記録、#249)。

## 感想と改善の案

1人で6日のあいだに、iOS の拡張機能4つ(うち Call Directory は中身の無い作り)と裏側と試験までを作れたのは、実装、検証、レビューを別のサブエージェントに分けたからだと思う。書いた本人と別の文脈のレビュー役が、こちらの思い込みを何度も崩した。2026年11月4日に作者の iPhone で初めてマイクを押して落ちたときも、実機の落ちた記録を読んで原因まで切り分けるところを Claude Code に任せられた(#57)。一方で、母が実際に使ったのは2026年11月7日の1日だけで、記録は [`docs/mother-feedback.md`](mother-feedback.md) に入れた。2台目の家族の実機で「電話する」を確かめること(#233)は、まだ作者の手を待っている。作るのは任せられても、本物の使い手の手と時間だけは前倒しできなかった。

### 日本語で使う立場から

利点は、言い方が人ごとに違う日本語の相談を、Claude がそのまま読めること。規則だけでは声の相談の詐欺32件のうち4件を見逃したが、Claude を足すと0件になった([`eval/RESULTS.md`](../eval/RESULTS.md) の2026年11月7日の最後の回)。

欠点は、英語の文に引かれると日本語に戻りにくいこと。2026年11月4日の夜、レビュー役の報告が英語で返り、それに引かれて主の応答まで英語になった。報告の1行目と日本語の割合を確かめるフック(`.claude/hooks/report-form.sh`)を足して止めた([`CLAUDE.md`](../CLAUDE.md) の「作業の流れ」)。日本語の語の一覧で文をふるう網にも弱さがあった。ウェブ検索で調べた営業時間の答えは、「開店」の「開」が「開く」を止める網に当たり、毎回1回目の答えに戻っていた(PR #252 の1回目のレビュー)。

### 1つだけ直せるなら

自由な文を語の一覧でふるう直し方に、早めに見切りをつける仕組みがほしい。「安全です」と伝えないための網は、#51、#53、#183 で、レビューのたびに抜ける言い換えが見つかり、そのたびに語を足していた。#183 では4回のレビューを経て、エージェントの文を家族に出すのをやめ、公式のサイトの URL だけを受け取る作りに変えた([`docs/dev-log.md`](dev-log.md) の2026年11月6日と7日の記録)。同じ種類の直しが2回続いたら、語を足すのではなく、自由な文を出さない作りに替えられないかを先に問う。これを Claude Code の skill かレビュー役の確かめの項目にしておけば、締切前の時間をもっと主役に回せたはずだ。

## 審査員用のリンク

TestFlight の公開リンクは <https://testflight.apple.com/join/EZhN4k78>(ビルド17。2026年11月8日に「審査員と家族」のグループで「テスト中」になった、#133。リンクから入れるのは100人まで)。ログインの情報は要らない。

体験モードでは、家族に入らずに、母の画面と家族に届くはずのカードを1台の iPhone で見られる。本当の家族には何も届かない。危なさは3段階で、どの経路でも「安全です」とは返さない。いちばん軽い3段階も「安全」ではなく「心配は少ない」の扱いで、メールやサイトの「これどう?」に3段階と答えるときも、「お金や暗証番号を聞かれたら止めて、家族に確かめて」の1行を必ず付ける。

1. TestFlight から入れて開く。家族には入らない
2. 最初の画面で、「見守られる人」「家族」の下にある3つ目のボタン「体験」を押す
3. 母の画面に「知らない人や勧誘の電話で困ったら教えてね」が出る。マイクを押すと、警察を名乗る電話についての母の相談と、1段階の答え、家族に届く通知とカードが出る
4. カードの「解決」を押して確かめの「解決にする」を押すか、「30分後」を押して誰も解決しなかったときの両方の画面を見る
5. 続いて SMS の欄が出る。架空の不在通知の例が入っていて、書き換えてもよい。「送る」を押すと、家族に知らせない `/sms/demo` で裏側の規則が判定する。「最初から」でやり直せる

体験モードがシミュレータで動くことは確かめた。TestFlight の版で出るかは #187 で確かめ待ち。
