## 概要

フォームに貼る文。2026年11月7日に Python の `len()` で数えて460字(500字以内)。

このプロジェクトは、離れて暮らす高齢の親が詐欺に一人で向き合うしかない状況を、親が何もしなくても家族が代わりに気づいて電話できる形に変える iOS アプリです。警察を名乗る電話で「口座が犯罪に使われた。誰にも言うな」と言われた母がいるとする。アプリは通話を聞けないので、3分以上の電話がアプリを開いたまま終わると「知らない人や勧誘の電話で困ったら教えてね」と声をかける。母がそのまま話すと、裏側の規則がニセ警察の筋書きを見抜いてすぐに答え、電話を切ってお金を動かす前に家族に確かめるよう伝える。家族全員の iPhone には、危なさの段階と何の相談かのカードが届く。家族の誰かが母に電話して「解決」を押すと、ほかの家族にも伝わる。知らない相手からの SMS、Gmail、Safari で開いたページは、母が何もしなくても見張る。危なさは3段階で、どの経路でも「安全です」とは返さない。スマホの使い方や天気のような質問には AI が答え、案内のあとも困っていれば家族に回す。毎朝の笑顔の写真で、何も無い日も家族とつながる。

## 使った Claude の製品

選ぶのは次の5つ。

- Claude Code。アプリ、拡張機能、裏側、試験のすべてを書いた
- Claude API。SMS、メール、ページの判定と、母との会話、スクショの読み取り、ウェブ検索に使う
- Managed Agents。知らせのあとに公式のサイトで注意喚起を探す裏の調べものに使う
- Claude in Chrome。TestFlight の配布と App Store Connect の画面の操作に使った
- claude.ai の Artifacts。作者向けのページを作るのに使った

作品の中で Claude API と Claude Managed Agents を使い、開発は Claude Code で進めた。モデル ID は2026年11月7日に Claude の公式ドキュメント([Haiku 5.5](https://platform.claude.com/docs/en/models/haiku-5-5/overview)、[Sonnet 5.5](https://platform.claude.com/docs/en/models/sonnet-5-5/overview))で確かめた。

### Claude API

SMS、メール、ページの判定は Claude Haiku 5.5(`claude-haiku-5-5`)に Structured Outputs で頼む([`server/src/claude.ts`](../server/src/claude.ts))。答えは段階、理由、母への1行の決まった形で、中の文が誰に知らせるかを変えられない。即答は規則が返し、Claude の判定は Cloudflare Queues で後から重ねる。

母との会話と、母が共有から送ったり、チャットの写真のボタンで選んだりしたスクショや書類の読み取りは Claude Sonnet 5.5(`claude-sonnet-5-5`)にした([`server/src/consult-judge.ts`](../server/src/consult-judge.ts))。写真のボタンはビルド14に入っていて、実機で確かめた記録はまだ無い(#187)。母は画面の前で待っているので、裏側は最大15秒待ち、間に合わなければ規則だけで答える。設定の画面のスクショには、押す場所に丸を付けて返す。

天気やお店の営業時間のような今の情報が要る質問は、ウェブ検索のツールで調べて答える(#251)。構造化出力は出典(citations)と一緒に使うとエラーになり、ウェブ検索は出典が必ず付くので([Structured outputs](https://platform.claude.com/docs/en/build-with-claude/structured-outputs)、[Web search tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool))、2回に分けた。1回目はいつもの構造化の判定で、検索する言葉も書かせる。2回目は構造化なしの Sonnet 5.5 にウェブ検索を付けて答えさせる。15秒の締切は2回の合計に当て、残りが6秒を切れば2回目を呼ばず、2回目が失敗したり網に当たったりしたら1回目の答えを返す。答えの終わりには出典を1つ付ける。サイト名を読むのは公的なサイト(`.go.jp` など)とよく知られたサイトだけで、ほかは「(ウェブで調べた結果)」にする。検索の上位に来た偽のサイトを、見に行く先として母に聞かせないためだ。2026年11月7日に本番で天気の質問を送ると、約7秒で「(weathernews.jp より)」の付いた答えが返り、家族には知らせなかった(#251 のコメント)。

### Claude Managed Agents

SMS、メール、ページで1段階か2段階の知らせが出たあと、急がない裏の調べものに使う([`server/src/agents.ts`](../server/src/agents.ts))。モデルは `claude-sonnet-5-5`、ベータの見出しは `managed-agents-2026-04-01` で、道具は `web_search` と `web_fetch` だけにし、開けるのは公式の20のサイトに絞った。家族のカードに足すのは、エージェントが挙げた公式のページのサイトから決めた1行(「<表示名>の注意喚起」)だけで、エージェントの書いた文は家族にも D1 にも出さない。2026年11月7日に本番で1回動いた。作者が Safari で試しのページを開くと、数分後、本番の D1 の知らせ2件に警察庁、国民生活センター、情報処理推進機構の注意喚起の3件が根拠として書かれていた(#187 のコメント)。家族のカードの1行は見ていない。

### Claude Code

アプリ、拡張機能、裏側、試験のすべてを Claude Code で書いた。1件の Issue ごとに、実装役(`mm-implementer`)、検証役(`mm-verifier`)、レビュー役(`mm-reviewer`)を別のサブエージェントにし、レビューの結果を PR に残してからマージした。役のモデルは途中で変えた。2026年11月4日から6日までは、レビュー役、監査役、採点役と、作者がいないあいだの autopilot の主を Fable で動かし、2026年11月6日に作者の判断でこれらを Opus に戻した。それ以降、Fable を使うのは advisor だけで、シミュレータの画面を見ない確かめ(`make verify`、試験、grep)の検証役には Sonnet も使った([`CLAUDE.md`](../CLAUDE.md) の「モデルの使い分け」、[`docs/dev-log.md`](dev-log.md) の2026年11月5日と6日の記録)。ハッカソンのルールと母のデータを守る決まりはフックで止めている(期間の前のコードを開く、holdout を読む、秘密を読む、レビューの無い PR をマージする、など)。仕組みは [`docs/harness.md`](harness.md) にある。

フックの記録では、2026年11月3日から7日までに、レビュー役を170回起動して21回再開し、実装役を76回、検証役を61回起動した。フックが止めたか作者の確認に回した操作は208回だった([`docs/claude-usage.md`](claude-usage.md))。`origin/main` には922のコミットがあり、マージを除く711のうち674に `Co-Authored-By: Claude` が付いている。マージした PR は119件、Issue は105件(閉じたもの74件)、レビュー役の報告の原文は [`docs/audits/raw/`](audits/raw/) に209件ある(`git ls-tree --name-only a916f02 docs/audits/raw/ | grep -c mm-reviewer`)。コミットの数は `git rev-list --count --no-merges --grep='^Co-Authored-By: Claude' a916f02` のように `a916f02` を付けて数え、PR と Issue の数は `gh pr list --state merged --limit 500 --json number --jq length` などで2026年11月7日に数えた値だ。コマンドの一覧は [`README.md`](../README.md) の「Built during the hackathon」にある。

## 一番詰まった場面

[`docs/dev-log.md`](dev-log.md) の2026年11月4日の記録「マイクを初めて押すと落ち、主役の一言は2段階だった (#57)」から取った。順番は記録のまま、時刻だけを外し、記録の後に分かったことを最後の段落に足した。

ほかの候補は2つある。2026年11月7日の記録「警察の相談のあとの「おはよう」が2段階で家族に届いた (#219)」は、作者の iPhone で見つけた不具合の直し方を、1回目のレビューで向きごと逆にし、2回目のレビューで相づちの一覧から「大丈夫」を外した場面だ。同じ日の記録「本番で天気の質問が家族に回った (#251)」は、試験がすべて通ったウェブ検索が、本番の1回目で天気の質問を家族に回した場面だ。

### 何を作ろうとしていたか

声の相談を作者の iPhone で初めて確かめていた(#57)。作者の iPhone を母の役、シミュレータを家族の役にし、アプリを消して入れ直して、許可を一度も聞かれていない状態から始めた。

### Claude にどう指示したか

作者がマイクを押したあと、Claude Code に「あれ、iPhoneのログみてくれますか」と頼んだ。

### 何が起きたか、期待との違い

音声認識の許可に答えた直後にアプリが落ちていた。`xcrun devicectl device copy from --domain-type systemCrashLogs` で取り出した落ちた記録の要所は `EXC_BREAKPOINT`、`closure #1 in closure #1 in static VoiceListener.permitted()`、`TCC __TCCAccessRequest_block_invoke_8` だった。直した版を入れ直すと、相談が本番の裏側に届いてから約1秒で家族の役のシミュレータに通知が届いた。ただ、「警察から電話があって、口座が犯罪に使われてるって」の段階は1ではなく2で、答えに「いったん電話を切って」が無かった。

落ちたのは、`@MainActor` の `VoiceListener` の中の閉包を TCC が裏のキューから呼び、Swift 6 の実行時のチェックが止めたためだった。同じファイルのほかの閉包は同じ理由で切り離してあり、ここだけ漏れていた。主役の一言は設計で1段階と決めていたのに、筋書きの規則の部品に「警察から電話」が無かった。試験(eval)は相談の例文も SMS と同じ規則に通していたので、dev の数字にも出ていなかった。

### どう対処したか

落ちた方は `permitted()` を `nonisolated` にし、閉包を `@Sendable` にして直し(PR #71)、入れ直して同じ流れを通した。2段階の方は、相談の筋書きの数え方にだけ「警察を名乗る相手からの連絡」を部品として足した(#72)。SMS とページの規則にも足す案は、銀行や警察の本物の注意喚起が「警察を名乗る電話」と「口座が犯罪に使われている」を並べて書くので採らなかった。eval が相談の道を測っていないことは #74 にし、今は相談を本番の道で測っている。直したあと、作者が自分の iPhone で1段階と決まった答えを確かめた(#77)。使ったのは `/mm-device`、`xcrun devicectl`、MobileBuildMCP でのシミュレータの操作、mm-reviewer(SIL に落として実行時のチェックの数を数えた)、mm-implementer。

## 問題が起きた製品、環境、原因

上の場面について書く。

製品は Claude Code。モデルは、実装役の定義どおり Opus で動かしていた。2026年11月4日の時点のモデル ID と Claude Code の版は記録に残していないので不明。開発の Mac は macOS、作者の iPhone は iOS で、どちらもその日の版は不明(2026年11月7日の時点では、Mac が macOS 27.2、作者の iPhone が iOS 27.2)。落ちたのは、許可を一度も聞かれていない状態からマイクを押した1回目で、直したあとは同じ流れで落ちていない。

## 公式の情報は十分に見つかったか

おおむね見つかった。Claude API のモデル ID、Structured Outputs の形、ウェブ検索のツールの料金と形は、`claude-docs` の MCP で公式の文書を引いて確かめてから書いた。構造化出力と出典を一緒に使えないことも、Structured outputs の文書の Feature compatibility で見つけ、ウェブ検索を2回の呼び出しに分けた。

見つからなかったものは2つある。アプリが止まっているあいだに通話の終わりを知れるかは、Apple の文書では決めきれず、Apple の DTS に聞いて、できないと答えをもらった([`docs/design.md`](design.md))。メールの判定で Claude を何秒まで待つかを決められる文書も無かった([`docs/dev-log.md`](dev-log.md) の2026年11月7日の記録、#249)。

## 感想と改善の案

1人で6日のあいだに、iOS の拡張機能4つ(うち Call Directory は中身の無い作り)と裏側と試験までを作れたのは、実装、検証、レビューを別のサブエージェントに分けたからだと思う。書いた本人と別の文脈のレビュー役が、こちらの思い込みを何度も崩した。上の場面のように、実機で落ちた記録を読んで原因まで切り分けるところも Claude Code に任せられた。一方で、母が実際に使ったのは2026年11月7日の1日だけで、記録は [`docs/mother-feedback.md`](mother-feedback.md) に入れた。2台目の家族の実機で「電話する」を確かめること(#233)は、まだ作者の手を待っている。作るのは任せられても、本物の使い手の手と時間だけは前倒しできなかった。

### 日本語で使う立場から

利点は、言い方が人ごとに違う日本語の相談を、Claude がそのまま読めること。規則だけでは声の相談の詐欺32件のうち4件を見逃したが、Claude を足すと0件になった([`eval/RESULTS.md`](../eval/RESULTS.md) の2026年11月7日の最後の回)。

## 審査員用のリンク

TestFlight の公開リンクは <https://testflight.apple.com/join/EZhN4k78>(ビルド14。リンクから入れるのは100人まで)。ログインの情報は要らない。

体験モードでは、家族に入らずに、母の画面と家族に届くはずのカードを1台の iPhone で見られる。本当の家族には何も届かない。危なさは3段階で、どの経路でも「安全です」とは返さない。いちばん軽い3段階も「安全」ではなく「心配は少ない」の扱いで、メールやサイトの「これどう?」に3段階と答えるときも、「お金や暗証番号を聞かれたら止めて、家族に確かめて」の1行を必ず付ける。

1. TestFlight から入れて開く。家族には入らない
2. 最初の画面で、「見守られる人」「家族」の下にある3つ目のボタン「体験」を押す
3. 母の画面に「知らない人や勧誘の電話で困ったら教えてね」が出る。マイクを押すと、警察を名乗る電話についての母の相談と、1段階の答え、家族に届く通知とカードが出る
4. カードの「解決」を押して確かめの「解決にする」を押すか、「30分後」を押して誰も解決しなかったときの両方の画面を見る
5. 続いて SMS の欄が出る。架空の不在通知の例が入っていて、書き換えてもよい。「送る」を押すと、家族に知らせない `/sms/demo` で裏側の規則が判定する。「最初から」でやり直せる

体験モードがシミュレータで動くことは確かめた。TestFlight の版で出るかは #187 で確かめ待ち。
