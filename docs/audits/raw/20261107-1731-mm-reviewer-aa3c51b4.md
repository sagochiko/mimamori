## 指摘

1. 書き足した [`docs/design.md`](~/develop/mimamori/docs/design.md) の115行目が、同じ段落の中で食い違っている(確度は高い)。段落の頭で「文字の欄の薄い文字は「相談・質問を入力してね」にする」と書いたのに、段落の終わりには元の `画面の文字は欄の名札(「メッセージ」)だけにし` が残っている。次に読む実装役やレビュー役が、どちらが今の決まりか分からない。終わりの文を「欄の薄い文字(「相談・質問を入力してね」)だけにし」のように直すべき。117行目の「写真のボタンとメッセージの欄」は欄を指す普通名詞なので、そのままでよい。

2. 「戻る」の読み上げの名前が、画面の文字と違う(確度は中。軽い)。[`ios/App/Views/FamilyHomeView.swift`](~/develop/mimamori/ios/App/Views/FamilyHomeView.swift) の74〜77行目で、見える文字は「戻る」なのに `accessibilityLabel("家族の画面へ")` で上書きしている。音声コントロールは `accessibilityLabel` で呼ぶので、画面を見た人が「戻るをタップ」と言っても押せない。`.claude/rules/ios.md` は消した説明を label と hint に残せと言っているだけで、見える語を label から外せとは言っていない。label は「戻る」のままにして説明は hint に置くか、`accessibilityInputLabels(["戻る", "家族の画面へ"])` を足すとよい。ボタンの語(1語の動詞)と hint の中身は決まりに合っている。

3. 薄い文字が大きな文字サイズで切れる(確度は中。軽い)。[`ios/App/Views/MessageField.swift`](~/develop/mimamori/ios/App/Views/MessageField.swift) の109〜119行目の `placeholderLabel` は `numberOfLines` が既定の1行で、右端が `lessThanOrEqualTo` で止まっている。11字の「相談・質問を入力してね」は、前の5字の「メッセージ」より切れやすい。アクセシビリティの大きな文字サイズで欄の幅を超えると、「相談・質問を…」と末尾が切れる。壊れはしないが、PR の本文が言うとおり画面は撮っていない。大きな文字サイズで1枚撮って確かめるとよい。この文字は `accessibilityLabel` にも入る(133行目)ので、VoiceOver の欄の名前も「相談・質問を入力してね」になる。これはおかしくない。

4. 試験が1件足りない(確度は高い。軽い)。[`ios/Core/Tests/MimamoriCoreTests/ProtectedPresenceTests.swift`](~/develop/mimamori/ios/Core/Tests/MimamoriCoreTests/ProtectedPresenceTests.swift) の足した試験は、`markJoined` で入ったことになり、起動し直しても残るところまでしか見ていない。頼まれた「戻るのあとに家族を抜けたら忘れるか」の流れ(`markJoined` のあと `forget` で `hasJoined == false`、さらに `update(smiles: [], cases: [])` が false)が試験に無い。今のコードは `forget` が無条件に false を書くので正しく動くが、`markJoined` に別の印を足すような変更が入ると気づけない。

## 確かめて問題なかったこと
