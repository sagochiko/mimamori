## 指摘(どれも軽い)

### 1. 軽い。前に案内しない話題があると、関係のない案内もその話題の言葉が入っていれば止まり、家族に回る
場所は `server/src/consult.ts` の `decidePlan` の `askedEarlier` と `guided`。前の母の言葉が「振込のやり方を教えて」で、写しで次のようになった。

```text
N1 「Wi-Fi がつながらない」、Claude「…入れ直して。暗証番号は誰にも教えないでね」 -> HANDOFF、認証コードに関わる相談、知らせ2件
N4 「Wi-Fi がつながらない」、Claude「…ネットワーク設定をリセットを試して」       -> HANDOFF、データの削除に関わる相談、知らせ2件
N5 「画面が暗い」、Claude「パスコードを入れて、明るさを上げて」                  -> HANDOFF、認証コードに関わる相談、知らせ2件
N2 「Wi-Fi がつながらない」、Claude はふつうの Wi-Fi の案内                     -> 案内が返る、知らせは0件
```

親が気にしていた「ふつうの案内まで止めないか」の答えはこうなる。言葉が SENSITIVE に当たらない案内は止めない(N2)。「暗証番号は教えないで」という注意や、「リセット」「パスコード」といった言葉が入った案内は止める。

家族への知らせが増えるのは、前の相談を家族が解決にしたあとだけだ。解決していなければ同じ相談に入り、段階も同じなので、知らせは増えない。直すなら、認証の型を「教えないで」のような注意の文では数えない、などが考えられる。

### 2. 軽い。今の言葉が電話やメッセージの話だと、仕込みのあとの困りごとまで1段階になる
場所は `server/src/consult.ts` の `consult()` の `goesOn`。仕込みのメールのあとの「電話の音を大きくしたい」が、`詐欺の手口と似ているところがあります。お金や暗証番号の話には応じず、家族に確かめて`、level 1、知らせ2件になった。写しで再現した。

CONTACT を続きとして数えるのは親の決めた形どおりで、「電話」の一語で当たる。家族への知らせが増えるのは、指摘1と同じく、解決にしたあとだけだ。

### 3. 軽い。action の確かめが help のときしか効かない
場所は `server/src/consult.ts` の `guided` の `claude.kind === "help"`。

Claude が scam の level 3 で「ATM の「振込」を押して口座番号を入れて」を返すと、`lowConcernReply` がそのまま読み上げる(写しの4e: `reply=ATM の「振込」を押して口座番号を入れて。お金や暗証番号を聞かれたら止めて、家族に確かめて`)。level 2 以下の `${basis}${action}` も同じで、こちらはコードで見ただけだ。

Claude が詐欺の相談としてわざわざ送金の手順を書くのは考えにくい。直すなら、`kind` の条件を外して、読み上げる action すべてに当てる。
