## 指摘

### 1. 根の終わりの「お」が「おそれ」の「お」を飲み込み、「あの、おそれがある」が前を指す側に倒れる(確度は高い。再現した)

場所は [`server/src/consult-judge.ts`](~/develop/mimamori/.claude/worktrees/issue-158-points-back-variants/server/src/consult-judge.ts) の426〜427行の `POINTS_BACK` と、[`ios/Core/Sources/MimamoriCore/Chat.swift`](~/develop/mimamori/.claude/worktrees/issue-158-points-back-variants/ios/Core/Sources/MimamoriCore/Chat.swift) の174〜175行の `pointing`。

コードのコメント(415行あたり)、PR の本文、新しい [`docs/design.md`](~/develop/mimamori/.claude/worktrees/issue-158-points-back-variants/docs/design.md) の205行の段落は、どれも「「お」を根にすると「おそれがある」が前を指すので足さない」と書いている。ところが、終わりの仮名がお段の根(`あの`、`で…も`、`ちょ…と`、`え…と`)は、伸ばしの中に素の `お` を許す(`[ーっぁぃぅぇぉお…]*`)。そのため呼びかけのあとの「おそれ」の `お` が伸ばしとして読まれ、残りの `それがある` が `(それ|これ|あれ)` に当たる。先に記号を消すので、「あの」と「おそれ」を分けていた `、` も残らない。これが根の原因になっている。Issue の完了の条件「「おそれがある」は今までどおり前を指さない」は、呼びかけが前に付くと満たされない。

手元で、作業の木のファイルは変えずに、正規表現を取り出して node で流した(O は main の型、N はこの PR の型。`-` は前を指さないと読んだもの)。

```text
- - おそれがある
- N あの、おそれがある
- N あのー、おそれがあるって
- N えーと、おそれがあるって
- N えっと、おそれがある
- N でも、おそれがある
- N ちょっと、おそれがある
- N えと、おそれがあるの
- N あの、おそれいりますが
- N でも、おそうなの
```

困る場面はこうなる。前の日にニセ警察の筋書きを話した母が、翌日、届いた SMS の「口座が凍結されるおそれ」を見て `あの、おそれがあるって?`(11字)と聞く。前を指すと読まれるので、60分を過ぎた前の日の会話6件が端末の外へ出る。そのうえ `pointsBackAtScript`(662行)が真になると、警察の決まった1行が付き、`topicWords` も前の母の言葉の話題を引き継ぐ。どちらも設計が「母の言葉を端末の外へ出さない側を選んだ」と書いたのと逆の側だ。

例の一覧([`server/test/fixtures/points-back.json`](~/develop/mimamori/.claude/worktrees/issue-158-points-back-variants/server/test/fixtures/points-back.json) の42行)にあるのは素の `おそれがある` だけで、この抜け道を捕まえる例が無い。

### 2. 素の「ね」を根にしたので、「ねこの〜」が「ね」と「この〜」に読まれる(確度は高い。再現した)

場所は指摘1と同じ正規表現。main の一覧の「ね」は `ねえ|ねぇ|ねー` だけだったが、この PR で素の `ね` が根に入った。依頼にあった「呼びかけでない語の頭が根の連なりとして読まれる」場合にあたる。

```text
- N ねこのこと
- N ねこの飼い方を教えて
- N ねこのやつ
- N ねこの写し方
- N ねそうなの
- N ねこれ
```

`ねこの飼い方を教えて` は `ね` と `この` + 漢字 + 仮名 + `方` に、`ねこのこと` は `ね` と `このこと` に当たる。声を仮名のまま文字にしたときや、母が仮名で打ったときに、前の日の会話が付く。倒れる向きは指摘1と同じだ。例の一覧の前を指さない例(`ねえさんのスマホ`)は「ねこ」を確かめていない。

### 指摘1と2に伴う設計の書きぶりの食い違い

[`docs/design.md`](~/develop/mimamori/.claude/worktrees/issue-158-points-back-variants/docs/design.md) の205行は「残るのは2つある」とし、根に無い呼びかけと15字を超える問いを挙げて、どちらも前を指さない側(送らない側)に倒れると書いている。実際には3つ目の残りがあり、それは前を指す側(送る側)に倒れる。お段の根の伸ばしが続く語の頭を飲み込む場合と、根が語の頭と同じ仮名の場合だ。設計の文はコードの振る舞いと合っていない。

直し方は実装役に任せる。語ごとの先読み(`お(?!それ)`、`ね(?!こ)`)なら両方の正規表現エンジンで書けるが、それは #84 / PR #159 と PR #156 で止まった「一覧で追う」に戻ることになる。根の原因は、呼びかけを見分ける前に記号を消して `、` の切れ目を失うところにある。どの直し方を選んでも、前を指さない例として少なくとも次を足すと、落ちる試験から始められる。

```json
{ "text": "あの、おそれがある", "pointsBack": false },
{ "text": "でも、おそれがある", "pointsBack": false },
{ "text": "えーと、おそれがあるって", "pointsBack": false },
{ "text": "ちょっと、おそれがある", "pointsBack": false },
{ "text": "ねこの飼い方を教えて", "pointsBack": false },
{ "text": "ねこのこと", "pointsBack": false }
```
