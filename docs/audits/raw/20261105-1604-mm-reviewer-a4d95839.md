### 1. 「筋書きの部品」の枝を試すはずのテストが、元に戻しても落ちない(低、再現した)

### 2. 「〜って載ってた」がふつうの日本語に当たる(低、直さなくてもよい)

`~/develop/mimamori/.claude/worktrees/issue-114-followup-handoff/server/src/rules/phrases.ts` の152行目と、その理由を書いた149〜150行目のコメント。

```ts
new RegExp(`${POLICE_NAME}(の人|の者|署員)?(を|って)(乗|載)(る|って|り(?!越)|った|られ)${NOT_A_WARNING}`),
```

コメントの「`を` か `って` のあとは乗り物では使わない」は乗るには成り立つが、載るには成り立たない。「警察って載ってた」は「警察と書いてあった、出ていた」のふつうの言い方で、1回目の指摘1と同じ種類の当たり方になる。tsx で確かめた結果、HEAD では筋書き(1段階の決まった答え、Claude を呼ばず家族に知らせる)になり、変更前は規則2段階で Claude に回っていた。

```text
"画面に警察って載ってたけど、逮捕状って何"   HEAD: caller=true script=true   9bfaa3d: caller=false script=false rule=2
```

向きは重く出るほうで、同じ言葉の中に筋書きの部品がもう1つ要り、テレビ、ニュース、新聞から聞いた話は `passed_on` で外れる。dev の誤報は 0/54 のまま(`eval/RESULTS.md` の15:53の行)。着信の表示やメッセージに「警察」と出ていて逮捕状の話もあるなら詐欺に近い場面でもあるので、実際に誤報になる場面は少ない(推測)。直すなら `(を(乗|載)|って乗)` にして載るは `を` のあとだけにする。作者の iPhone が実際に書いた「警察を乗る」はそのまま残る。今のままで通しても主役は壊れない。

## 確かめて問題なかったこと

### 1回目の4つの指摘が解けていること

指摘1(乗るの型)。`と` を外し、`り(?!越)` で乗り越えるを除き、載るを足した。1回目で再現した4文はすべて負のテストに入り、HEAD で通る。`make eval-rules` の結果は15:27の行(直す前)と15:53の行で、見逃し 17/60、誤報 0/54、本物の1段階 0 と同じ(`eval/RESULTS.md`、`eval/results.jsonl` の `git_sha` は `25bdd35`)。

指摘2(設計の一文)。「AI が答えきれない相談と、2段階目以上の知らせは、相談1件として記録する」の直後に「ただし、前を指すだけで指す先の無い問いかけ…は、答えきれない相談に数えない。AI が何のことかを聞き返し、記録もしない」と但し書きを付けた形で、並べて足しただけの矛盾は無い。

指摘3(D1 の2列)。`docs/plan.md` の D1 の表の下の1行は、`server/src/consult.ts` の239〜240行目の UPDATE が `level`、`reasons`、`summary` と一緒に `rule_level`、`claude_level` を書き替えることと一致する。

指摘4(「これ、警察から」)。probe で HEAD は家族(2段階、`HANDOFF`)、`9bfaa3d` は聞き返しになった。「それ警察の人」も同じ。

### `namesSomething` の広げ方が狭める向きにだけ働くこと

`server/src/consult-judge.ts` の430〜439行目は OR の項(`POLICE_WORD`、`POLICE_SCRIPT`、`MONEY_MOVE`)を足しただけで、`pointsAtNothing`(446〜448行目)は `every((t) => !namesSomething(t))`。`namesSomething` が真になる入力が増えるほど `pointsAtNothing` は偽になるだけなので、聞き返し(684行目)に入る集合は縮む一方で、家族に回るべき問いが聞き返しになる新しい道は無い。`POLICE_WORD` と `namesSomething` を使う場所はこの1か所だけ。`POLICE_WORD` は `g` 無しの `RegExp` なので `.test` の `lastIndex` の持ち越しも無い。

probe でも、「それってどういうこと」単独、前の母の言葉も同じ、AI の行だけに「警察から電話があったんですね」がある、の3つはすべて聞き返しのまま(AI の行は `said.earlier` に入らないので、AI の行の文で結果は変わらない)。「それ刑事ドラマ？」は家族へ回る(重くなる向き)。

### 設計に足した文と実装の条件

「スマホ相談と声」の文は684行目と項ごとに対応する。案内しない話題は `sensitive.length === 0`、メッセージや電話の話は `CONTACT`、警察の語や筋書きの部品は `POLICE_WORD` と `POLICE_SCRIPT`、`MONEY_MOVE`(お金を動かす話は設計の筋書きの一覧「送金や口座の移し替え」に含まれる)、規則や Claude が見た印は `rule.level === null && level === 3`(`injection_suspected` で上がった分も `level` に入る)、Claude の答えが無いときは `claude?.handoff` が偽。

「家族への知らせと解決」の知らせ直しは、`consult.ts` の `level > ? OR (? = 1 AND level = 2 AND COALESCE(claude_level, rule_level, 3) = 3)` と合う。文の頭は「答えきれずに家族に回した2段階の相談」だが、実装の定義は括弧の「詐欺の印は無い」のほうで、印の無い2段階で開く道は handoff(印なし)、案内しない話題、Claude の答え無しの3つ。`consult.test.ts` の2532行目のテストが3つとも通す。文の頭だけを読むと狭く取れる余地はあるが、動きは括弧のとおりで知らせが増える向きなので指摘にはしない。「それ以外の相談が加わっても、知らせ直さない」は2つ目の `?` が0のとき UPDATE が走らないことと合う。

### 新しい型のほかの当たり方

HEAD で probe した結果、「警察を乗っ取って」「警察を乗せて」「警察を載せた新聞で」は当たらない。「警察官をのる人から」(ひらがな)は当たらず、1回目に書かれた前からの見逃しのまま。「警察を乗り換えて」は当たるが、ふつうの日本語ではない(警察署で乗り換える)ので挙げない。「警察官って乗ってた」は変更前から当たる。
