## 指摘

1. 目的語の無い「全部消して」と、「スマホ」「アイフォン」の言い方の初期化や消去が、言葉の網を抜けるようになった(挙動は確度が高い。重さは中)

   [`server/src/consult-judge.ts`](server/src/consult-judge.ts) の155〜166行の新しい `SENSITIVE` の項目に node で当てた結果。
   ```text
   guided	全部消して
   guided	サポートの人に全部消してって言われた
   guided	AnyDeskを入れたあと全部消してと言われた
   guided	中身を全部消して
   guided	スマホの中身を全部消したい
   guided	スマホをリセットしたい
   guided	アイフォンをリセットしたい
   guided	アイフォンを消去したい
   guided	スマホを消去
   guided	iPhoneを工場出荷の状態に戻す
   guided	iPhoneを消して
   family [初期化]	初期化して
   family [写真を全部消]	AnyDeskを入れて写真を全部消してと言われた
   ```
   規則も同じ文を見逃す。`judgeByRules` は「サポートの人に全部消してって言われた」「AnyDeskを入れたあと全部消してと言われた」「サポートの人にスマホをリセットしてと言われた」「電話の人にアイフォンを消去してと言われた」のどれにも `level: null` を返した。遠隔操作の規則([`server/src/rules/phrases.ts`](server/src/rules/phrases.ts) の390行)は「入れて」「入れる」しか見ず、「入れたあと」に当たらない。

   前の版の網(`(すべて|全部|ぜんぶ).{0,8}(消去|消し|…)` と単独の `リセット`)は、これらを言葉だけで家族に回していた。今は Claude が案内しない話題と読んで handoff を立てるかどうかに頼っている。プロンプトはそう指示しているので、Claude が従えば家族に回る。Claude が答えなかったときも2段階で家族に回る。困るのは、Claude が kind を help、handoff を false で返したときだ。その場合はこうなる。
   - 「スマホをリセットしたい」「アイフォンを消去したい」では、Claude の案内がそのまま読み上げられる。`DELETION` から `リセット` を外したので、「リセット」の文には確かめの一言も付かない。
   - 「サポートの人に電話で全部消してと言われた」は `CONTACT` に当たるので、3段階の決まった1行になり、家族には知らされない。

   作者が家族に回すと決めたのは「iPhone の初期化、消去、まるごとのリセット」と「写真やデータを全部消すこと」だ。母が端末を「スマホ」「アイフォン」と呼ぶこと、詐欺の側が「全部消して」としか言わないことは十分ありうる。

   直し方の案は2つある。
   - 端末の語に `スマホ|アイフォン|あいふぉん` を足し、`工場出荷.{0,6}(戻|状態)` と `中身` を足す。
   - 目的語の無い「全部消して」は、句の頭にあるときだけ当てる。たとえば `(^|[、。 ]|に|で|と|から)(すべて|全部|ぜんぶ)を?(消|削除)` のような形にする。こうすると「通知を全部消したい」(前が「を」)は当たらず、作者が決めた案内のままにできる。
   
   どちらも試験を1件ずつ足す。作者の範囲の外へ広げる変更ではない。

2. 画像の相談と、前に案内しない話題があった会話では、ネットワーク設定のリセットの正しい案内が家族に回る(確度は高い。重さは低〜中)

   ネットワーク設定のリセットの案内は、iOS の画面の名前「転送またはiPhoneをリセット」を必ず含む。この名前が `(…|転送または).{0,8}リセット` と `iphone.{0,8}リセット` の両方に当たる。
   ```text
   family [転送またはiphoneをリセット]	設定の「一般」から「転送またはiPhoneをリセット」の「リセット」で「ネットワーク設定をリセット」を押して
   ```
   言葉だけの相談なら Claude の文に網をかけないので、追加された試験(`consult.test.ts` の「a network settings reset」)は通る。ところが、画像があるときは `claudeLines` が Claude の `action` にも網をかける(921〜936行)。前の発言が網に当たった会話(`askedEarlier`)でも同じだ。たとえば Wi-Fi の画面のスクショに「つながらない」と添えた相談は、Claude が正しく案内しても家族に回り、AI は答えない。作者の「ネットワーク設定のリセットは AI が案内する」(`docs/design.md` の221行)と食い違う。画像でこの経路を通す試験は無い。

   直し方の案は2つ。Claude の文に当てるときは、画面の名前の「転送またはiPhoneをリセット」を除いてから網をかける。または、Claude の文では `コンテンツと設定` と `初期化` だけで消去の案内を見分ける。画像でネットワーク設定のリセットを案内する試験を1件足す。

3. 「iPhoneのパスワードをリセットしたい」が家族に回る(確度は高い。重さは低)

   `iphone.{0,8}リセット` が「iphoneのパスワードをリセット」(間は7字)に当たる。作者はパスワードのリセットを AI の案内にすると決めた。ただ、守る側に倒れる食い違いなので、直すのは指摘1と2のついででよい。`(?!.{0,8}(パスワード|パスコード|ネットワーク))` のような除外を考えるとよい。
