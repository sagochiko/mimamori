## 指摘の一覧

### 1. 軽い(推しは直す)。母が言いそうな「警察を名乗る電話」と「警察庁」を取りこぼす
場所は server/src/rules/phrases.ts の99〜111行(`POLICE_NAME` と3つの正規表現)。

作業の木の phrases.ts と rules/index.ts を tsx で読み込み、`tellsPoliceScript` と同じ数え方(NFKC と小文字にしてから数える)で流した。どれも `police_account_crime` には当たるのに、caller が false になり、Claude に回る。

```text
警察を名乗る電話がきて、口座が犯罪に使われてるって   caller=false after=false
警察庁から電話があって、口座が犯罪に使われてるって   caller=false
警察庁の人から電話で、口座が犯罪に使われてるって     caller=false
刑事を名乗る人から電話で、口座が犯罪に使われてるって caller=false
警察ですって電話で、口座が犯罪に使われてるって       caller=false
警察からだっていう電話で、…                           caller=false(「から」のあと5字)
```

原因は2つある。2つ目の形は「を名乗る」のあとに `(人|方|者|男性?|女性?|相手)` しか受けず、「電話」が入っていない。3つ目の形は `(って|と)` だけで「を」を受けない。もう1つ、`警察(署|官)?` に「庁」が無いので、「警察庁」は「警察」のあとで切れる。

当たったときは、主役の一言と同じく Claude に回るので、本番では #72 と同じ2段階に戻りうる。2つ目の形に `電話` を足し、`POLICE_NAME` に `警察庁` を足せば足りる見込みだ(足したあとは試していない)。

当たるほうも確かめた。「警察だって人から電話で」「大阪府警の人から電話で」は当たる。

### 2. 軽い(設計の判断)。母が本物の注意喚起を話すと、規則だけで1段階になる
場所は server/src/consult.ts の337〜343行。

SMS には足さない理由として PR が挙げたのと同じ形の文が、母の口から来ると1段階になる。どれも Claude を呼ばずに決まった答えになり、家族に「1段階」が届く。上と同じスクリプトで、`before` が false、`after` が true になった。

```text
交番の警察の人が、口座が犯罪に使われてるって電話は詐欺だから気をつけてって言ってた
警察から電話があって、口座が犯罪に使われてるっていう詐欺が増えてるから気をつけてって
テレビで、警察を名乗る人から口座が犯罪に使われてるって電話が来る詐欺をやってた
警察の方で調べてもらったら、口座は犯罪に使われてなかったって
```

この型の誤報は前からある。筋書きの部品2つ(口座と逮捕など)を本物の注意喚起として話したときも同じになる。今回は「警察の人が」「警察の方で」という、ごく普通の言い方で広がった。

dev の consult の本物の警察(c-gp-01〜07)と本物の銀行には、こういう伝え聞きの例文が無い。なので dev ではこの誤報が見えない。

選べる道は3つある。この取り引きを受け入れてテストに1件残す。「詐欺」「気をつけて」「なかった」が近くにあるときは筋書きにしない。テストで扱いを決めずに別の Issue にする。主役の一続きを優先するなら、受け入れたうえでテストか dev-log に残すのが推しだ。確かめ方は再現。
