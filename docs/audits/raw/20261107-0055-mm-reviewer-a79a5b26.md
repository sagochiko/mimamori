## 指摘

1. 3段階の画像の相談では、Claude の根拠(`basis`)を通って危ない勧めが母に読まれる。直しは勧めの穴を `action` から `basis` へ移しただけになっている(確度は高い。`judgeConsult` を直接呼んで再現した)

   場所は [`server/src/consult-judge.ts`](~/develop/mimamori/.claude/worktrees/issue-13-screenshot/server/src/consult-judge.ts) の行 942 にある `const basis = readable(claude.basis) ? claude.basis : "";` だ。`readable` が止めるのは、言い切りと安心させる語、「家族に伝えました」、判定の言葉だけになる。`SENSITIVE` と `CONTACT` はここで見られていない。画像だけの相談なので `ownSensitive` も空になり、`sensitive` の分かれ(行 906)にも入らない。

   画像の文字が Claude を誘導して、`basis` に勧めを書かせたとする。答えはそのまま3段階になり、家族への知らせも無い(`toFamily: false`)。`judgeConsult("", [], ask, undefined, true)` で、`kind: "scam"`、`level: 3`、`action: ""` を渡した結果は次のとおり。

   ```text
   basis link | 3 false | 銀行からの通知です。リンクから手続きを進めてください。お金や暗証番号を聞かれたら止めて、家族に確かめて
   basis code | 3 false | 本人確認のため、届いた認証コードを入力する必要があります。お金や暗証番号を聞かれたら止めて、家族に確かめて
   basis app  | 3 false | セキュリティのため、表示されたアプリを入れてください。お金や暗証番号を聞かれたら止めて、家族に確かめて
   basis call | 3 false | 表示された番号に電話して確認してください。お金や暗証番号を聞かれたら止めて、家族に確かめて
   basis pay  | 3 false | 未払い料金があるので、コンビニで支払ってください。お金や暗証番号を聞かれたら止めて、家族に確かめて
   ```

   プロンプト(行 312)は `basis` を「見えた根拠を一文で」と頼んでいる。それでも、画像に注入された文がこの頼みに従わせない道は塞がれていない。追加した試験は `basis: ""` で固めてあるので、この道が開いていても落ちない。直し方は2つある。ひとつは、画像で scam の3段階なら `basis` も捨てて、答えを `LOW_CONCERN_ACTION` だけにすること。もうひとつは、`basis` に `SENSITIVE` と `CONTACT` を当て、当たれば捨てること。網では良い文と見分けられない、というのがこの直しの理由だった。それなら前のほうが筋が通る。[`docs/design.md`](~/develop/mimamori/.claude/worktrees/issue-13-screenshot/docs/design.md) に足した1文の「見えた根拠と決まった…だけにする」も合わせて直す。足す試験は、上の `basis` の2件(リンクと認証コード)で、答えにその文が入らないことを確かめるもの。

2. 2段階の scam の答えでは、画像でも画像でなくても Claude の `action` を `readable` だけで読み上げる(行 931 から 935)。この直しで生まれたものではない(確度は高い。再現した)

   `level: 2`、`basis: "宅配の通知に見えます。"`、`action: "リンクを開いて再配達の手続きを"` を渡すと、答えは `宅配の通知に見えます。リンクを開いて再配達の手続きを` になった(`toFamily: true`)。家族には知らせが行く。ただ、警告のはずの答えで母に「リンクを開いて」と言っている。このPRで直すか、別の Issue にするかは親が決めてよい。1段階と2段階を変えないという直しの範囲からは外れる。
