## 指摘

### 1. 新しい型が相談だけでなく SMS、Gmail、ページにも効き、本物の注意喚起を迷惑フォルダに回す(確度: 高い。再現した)

[`~/develop/mimamori/.claude/worktrees/issue-51-rules-rest/server/src/rules/phrases.ts`](~/develop/mimamori/.claude/worktrees/issue-51-rules-rest/server/src/rules/phrases.ts) の28行目の型は `INJECTION`(strong)に入っている。`judgeByRules` は `check(INJECTION)` を経路を問わず流す([`server/src/rules/index.ts`](~/develop/mimamori/.claude/worktrees/issue-51-rules-rest/server/src/rules/index.ts) の298行目)。Issue の6も PR の説明も「相談で」の話なのに、型は経路で絞っていない。

否定の先読みで外しているのは `(?!たら|ても)` だけだ。警察や銀行の注意喚起がふつうに使う「と言われた場合は」「と指示されることがあります」「と頼まれた場合は」「と言われるかもしれない」は当たってしまう。`INJECTION` が当たると1段階になる(`levelOf`)。ほかに medium の印が1つあって公式の `https://` が無ければ `confident` が付き、`sms.ts` の94行目で `junk` になる。plan の「本物の SMS を迷惑フォルダに送る」失敗にあたる。

`npx tsx` でこのブランチの `judgeByRules` に流した結果を貼る。

```text
sms   「【注意】警察を名乗る電話で「見守りアプリの通知を切って」と指示されることがあります。逮捕状が出たと言われても応じないで」
      → {"level":1,"reasons":["警告を止めさせようとする文がある","逮捕や捜査をほのめかす話がある"],"confident":true}
page  「ニセ警察詐欺の手口。犯人は「その通知は消してください」と言い、言われた通りにすると口座が犯罪に使われたと話を進めます。」
      → {"level":1,...,"confident":true}
sms   「【警察署からのお知らせ】犯人から「この通知を止めて」と言われた場合は詐欺です。」
      → {"level":1,"reasons":["警告を止めさせようとする文がある"],"confident":false}
gmail 「犯人に「その知らせは無視してください」と言われた場合でも、お金を振り込まないで。」
      → {"level":1,...}
```

1つ目の SMS は、main では「逮捕」の medium が1つだけなので2段階で、`confident` は付かない。main の型は「見守りアプリの通知を切って」にも、リンクの無い文にも当たらないからだ。このブランチでは迷惑フォルダに入る。迷惑フォルダに入らない場合でも、本物を1段階にして家族に「開かないで」を飛ばすことになり、README が0件を目標にしている `genuine_at_level1` が増える。dev の114件が動かなかったのは、こうした本物の注意喚起が dev に無いからで、安全の裏付けにはならない。

直し方の案は2つ。1つは型を `input.source === "consult"` のときだけ流すこと(Issue の範囲と合う)。もう1つは否定の先読みに `た場合|る(か|こと)|ること` などを足すこと。どちらにしても、上の SMS、Gmail、ページの文を本物の側の否定のテストとして [`server/test/rules.test.ts`](~/develop/mimamori/.claude/worktrees/issue-51-rules-rest/server/test/rules.test.ts) に入れるべきだ。今の否定の例は6件ともすべて相談で、SMS とメールの本物の例が1件も無い。

### 2. 家族自身が「通知を止めて」と頼んだ相談も1段階になる(確度: 高い。再現した。重さは低い)

`娘に、この通知を止めてって言われたんやけど` と `見守りの通知を切ってって息子に頼まれた` は、どちらも `level: 1`、理由「警告を止めさせようとする文がある」になる。相談の経路なので家族に知らせが飛び、それが一番重い段階のカードになる。頼んだ当の家族に、母が詐欺の筋書きの中にいるように見せてしまう。否定のテストにある `息子に通知を止めてもらった` は「言われ」の形でないので、この形を確かめていない。相談の中なら家族に回すこと自体は害が小さく、直すかどうかは判断に任せる。ただ、`(この|その|あの)` に続く「知らせ」「お知らせ」まで含めた広さと合わせて、意図した範囲かを PR に書いておくとよい。

`この通知を止めてと言われていたら、どうする?` も、「言われ」のあとが「てい」なので先読みをすり抜け、1段階になる。
