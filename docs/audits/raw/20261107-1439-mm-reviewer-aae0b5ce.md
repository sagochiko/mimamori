## 指摘

1. 漢字の「全て」が網のどこにも入っておらず、全部の消去が AI の案内に回る(確度は高い。実測した)

   場所は `~/develop/mimamori/server/src/consult-judge.ts` の 170〜172行で、3つの句がどれも `(すべて|全部|ぜんぶ)` しか持っていない。NFKC をかけても「全て」は「すべて」にならない。実測では次の4つが `guided` になった。

   - `写真を全て削除`
   - `スマホの中身を全て消して`
   - `全てのデータを消して`
   - `全て消して`

   同じ意味の `全部の写真を消したい` と `スマホの中身を全部消したい` は家族に回る。「写真、データ、連絡先を全部消すこと」は家族に回すと作者が決めている(`docs/design.md` の221行あたり)ので、表記の違いだけでそこから外れている。

   Claude の文に網を当てる経路も同じで、`パスワードをリセットしたら、転送またはiPhoneをリセットで全て消去` は画面の名前が除かれたあと、どの句にも当たらずに通った。音声の書き起こしや手で打った文では「全て」がふつうに出てくるので、サポート詐欺の「中身を全て消して」が網を抜ける場面はありうる。

   後ろにはまだ Claude の指示(374行の「写真やデータを全部消すことは案内しません。そのときは handoff を true」)があるので、即座に案内されるとは限らない。それでも、決まった判定の層に穴が残る。直しは3か所に `全て` を足すだけで済む。`写真を全て削除` と `スマホの中身を全て消して` を `consult.test.ts` の家族に回す側の例に足すとよい。

2. 軽いもので、どれも見逃し側に倒れる(確度は中。実測した)

   - `スマホを初期状態に戻して` と `スマホを買った時の状態に戻して` は `guided` になる。網にあるのは「工場出荷」と「初期化」だけ。母の言い方としてはありうるので、「初期状態」は足す価値がある。
   - 目的語の無い `一気に全部消して` と `一度に全部消してって言われた` は、`(?<!一度|一気)に` で除いたため `guided` になる。`通知を一度に全部消したい` を案内に回すための除外だが、目的語が無いときまで通っている。目的語が先にあるかで分けられるとよい。
   - `全部リセットして` は `guided` になる(`iPhoneを全部リセット` は家族に回る)。
   - `全部 消して`(あいだに空白)と `ぜんぶけして`(仮名)は `guided` になる。書き起こしでは出にくいので優先度は低い。
   - `スマホの写真以外を消去` は、`ONE_THING` の否定先読みが「写真」を見て止めるので `guided` になる。`スマホの写真以外を全部消去` のように「全部」が付けば家族に回る。
