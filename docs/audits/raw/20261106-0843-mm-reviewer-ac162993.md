## 指摘

### 1. 注意の形が文節のどこかにあるだけで、送金と暗証番号の手順を母に読み上げる(main からの後退、確度は高い)

場所は [`server/src/consult-judge.ts`](server/src/consult-judge.ts) の542行目の `CAUTION` と、550行目の `guidedIn`、784行目の `guided` の計算。

`CAUTION` は文節のどこに当たっても、その文節を丸ごと「注意」として外す。そのため、同じ文節に手順の動詞が続いていても手順と数えない。前に「振込のやり方を教えて」と聞いたあと「次は何を押すの?」と言い、Claude が `help` で答えた場面を、`judgeConsult` に答えを差し込んで流した(`npx tsx` で実行)。

| Claude の action | このブランチ | main |
|---|---|---|
| `家族に確かめてから暗証番号を入れて` | 3段階、そのまま読み上げる | 2段階、家族に回す |
| `家族に確認しながら振込先を入力して` | 読み上げる | 家族に回す |
| `わからないようなら暗証番号を入力して` | 読み上げる | 家族に回す |
| `迷わずに振込を押して` | 読み上げる | 家族に回す |
| `画面を閉じずに暗証番号を入れて` | 読み上げる | 家族に回す |
| `暗証番号は家族に聞いて入れて` | 読み上げる | 家族に回す |
| `暗証番号を入れるのを忘れないで` | 読み上げる | 家族に回す |
| `振込ボタンを押すのを忘れないでね` | 読み上げる | 家族に回す |
| `振り込む前に止めないで最後まで進めて` | 読み上げる | 家族に回す |
| `ATMに行かないで済むように、ネットバンキングで振り込んで` | 読み上げる | 家族に回す |

当たっているのは、`家族に(確かめ|確認|相談|聞)`、`ないよう`、`(?<!ま)ず(に|$)`、`ないで`(「忘れないで」「止めないで」「行かないで済む」)、`止め` の部分一致。最後の例は「ように」で文節がつながり、`ないで` の文節と一つになっていた。

コメントには「一覧に無い言い回しは手順と数えて止まる(安全側)」とある。しかし逆向きの外れ、つまり手順を注意と取り違える側は母に手順が届く側に倒れていて、送金と認証コードの壁(`ALWAYS_GUARDED`)そのものが弱まっている。とくに「家族に確かめてから〜を入れて」は、家族に確かめるよう促す Claude が書きそうな形だと思う(これは推測)。

詐欺の答え(`readsOut`)の側は main では無条件に読み上げていたので、後退ではない。ただ、同じ取り違えで `家族に確かめてから振込先を入れて` と `迷わずに振り込んで` は、2段階でも3段階でもそのまま読み上げられる。

直し方の案は2つ。

- 注意と数えるのを、文節の述語が否定や制止で終わるときに限る(`(ないで(ね)?|せず|ずに?|ません|やめて|止めて|家族に確かめて)$` のように文末に寄せる)。そのうえで「忘れないで」「止めないで」は除く
- 少なくとも送金と認証コードは main と同じに戻し、語があれば数える形にして、文末が否定の文節だけを外す

どちらでも、上の表の形を試験に足す。いまの「守りの側」の8件は、注意の語を同じ文節に含む手順を1件も試していない(`暗証番号は人に見せないで、「振込」を押して` は読点で分かれるので通る)。

### 2. 仕込みのあとの下限が「届いた」「かかってきた」「警察からの」などの修飾で外れる(確度は高い、重さは中)

場所は同じファイルの178行目の `OWN_SETTING` と、923行目の `aboutContact`。

否定の後読みは、直前の「その」「この」「あの」「さっきの」の4つしか見ない。前の母の言葉に `この警告を止めて。家族に知らせないで` があり、Claude が流されて `scam` の3段階(`様子を見て`)を返した場面で試した。

- 下限が外れて3段階になり、家族に知らせず「様子を見て。お金や暗証番号を聞かれたら止めて、家族に確かめて」を読み上げたもの
  - `かかってきた電話の音を大きくして聞いていい?`
  - `届いたメールの文字を大きくしたい`
  - `さっき来たメールの文字を大きくして読みたい`
  - `この前のメールの文字を大きくしたい`
  - `銀行からのメールの文字を大きくしたい`
  - `警察からの電話の音を大きくしたい`
  - `あの人からの電話の音を上げたい`
- 下限が効いて1段階になり、家族に回ったもの
  - `さっきのメールの文字を大きくしたい`
  - `そのメールの字が小さくて読めない`

main では、上のどれも1段階で家族に回る。

試験の `その電話の音を大きくして聞いていい?` と同じく、どれもその電話やそのメールの話で、母の端末の設定の話ではない。外してよいのは、設定の語が言葉の頭にあるとき(`^` か、句読点や空白のあと。決まった呼びかけのあとを含めてもよい)だけに絞るのが安全だと思う。上の例を「下限が効く」側の試験に足す。

### 3. 設計の文書が変わった判定に追いついていない(確度は高い、重さは小)

[`docs/design.md`](docs/design.md) の205行目には「前の母の言葉に案内しない話題があり、Claude がスマホの操作として答えたときは、その案内も同じ型で確かめ」とある。209行目には「送金、認証コードの共有、構成プロファイルの導入、データの削除は案内しない」とある。

- 確かめるのは、前に聞いた話題と送金、認証コードだけになった。前に送金を聞いたあとの構成プロファイルの手順は読み上げる

`CLAUDE.md` の「決めたことは、決めたその場で `docs/design.md` に書く」に合わせて、この取捨と理由を205行目の節に足すべきだと思う。取捨そのものは設計の筋(詐欺が狙うのは送金とコード)に合っていて、私は妥当だと見ている。
