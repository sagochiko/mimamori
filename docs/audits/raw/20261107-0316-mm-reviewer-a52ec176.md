## 指摘

直すべき指摘は無い。軽いものが2つある。

### 1. 足した部品と別の中くらいの印が並ぶと、Claude が落ちたときだけ1段階で家族に届く(軽い。直さなくてよいと判断した)

実装役が残したおそれは、実際に起きる。足した部品と、`credential` や `prize_refund` のような中くらいの印が並ぶと `medium >= 2` になり、規則が1段階を付ける([`server/src/rules/index.ts`](server/src/rules/index.ts) の `levelOf`)。8a76028 で `tsx` に流して確かめた。

| 文 | 規則 | Claude が落ちたとき |
|---|---|---|
| `警察から電話があって、詐欺グループの名簿にわたしの名前があったって。被害金の返金の手続きを案内しますって` | 1(police_named と prize_refund、confident は false) | 1 |
| `警察から電話で、事件にあなたの名前が出てる、暗証番号を教えてって` | 1 | 1 |
| `警察から、わたしの名義の携帯が詐欺に使われたって。パスワードを変えてくださいって言われた` | 2(credential に当たらない) | 2 |
| `警察から電話で、盗まれたキャッシュカードが見つかったから、警察官が家に届けに来るって。カードの暗証番号を変えてくださいって` | 2 | 2 |

直さなくてよいと判断した理由は3つある。

- 1段階になる組み合わせは、警察が暗証番号を求める話と、警察が返金の手続きに誘う話だ。どちらも本物の警察はまずしない、詐欺の側の形だった。本物に近い形(暗証番号を変えて、と勧める話、パスワードの変更)は `credential` に当たらず、2段階のままだった
- 1段階のまま届くのは `decide` の `claude === null` のときだけだ。`confident` は false なので、Claude が答えれば Claude の段階が勝つ
- 中くらいの印が2つで1段階、Claude が落ちたら規則だけで知らせる、という形はこの PR より前からある設計だ([`docs/design.md`](docs/design.md) 262行目)

ただ、設計の新しい段落の「単独ではいくつ並んでも2段階までにして Claude に回す」は、足した部品どうしの話としては正しいが、別の印と並ぶ場合を書いていない。直すなら、その段落に「足した部品と別の中くらいの印が並べば規則は1段階になり、Claude が答えれば Claude の段階による」の一文と、上の1行目の文を固定するテストを足す程度で足りる。

### 2. 元の部品を広げた言い方どうしの組み合わせは、筋書きにならなくなった(軽い。意図どおり)

`LINEで令状を見せられて、明日逮捕に来るって` と `逮捕されたくなかったら示談金を払えって言われたの` は、1回目の版では筋書きだった。今は `does not tell the script` の側に移っている。どちらも詐欺の形だが、2段階で Claude に回り、Claude が答えられなくても2段階で家族に届く。指摘1の誤報を止めた代わりに見逃しの側へ倒したもので、dev の見逃しが 5/60 から 6/60 に1件増えたのもこの分と読める(どの1件かは確かめていない)。テストを弱めたのではなく、判断を変えたものだ。
