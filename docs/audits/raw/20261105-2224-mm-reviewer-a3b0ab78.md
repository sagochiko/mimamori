## 確かめて問題なかったこと

- 差分の範囲。`.claude/agents/` の6ファイル、`.claude/settings.json`、`CLAUDE.md`、`docs/harness.md`、`scripts/test-hooks.sh` の10ファイルで、31行の追加と31行の削除。判定の段階、通知先、削除、`ios/Core`、`server` には触れていないので、計画と設計との食い違い、注入の経路、iOS だけのフレームワークの取り込みは対象外。
- 値が揃っている。自己テストの `fm` で読んだ frontmatter は `mm-auditor` fable/medium、`mm-eval-curator` opus/medium、`mm-implementer` opus/medium、`mm-judge` fable/medium、`mm-reviewer` fable/medium、`mm-verifier` opus/medium。`.claude/settings.json` は `modelSettings` の `claude-opus-5-5` と `claude-fable-5-1` がどちらも `medium` で、上の階の `effortLevel`、`maxEffortLevel`、`env` は無い。CLAUDE.md の表の8行と docs/harness.md の表の6行も medium。
