[`docs/audits/2026-11-04-0815-winners.md`](docs/audits/2026-11-04-0815-winners.md) の19行は「4.8 は自律と統率をセッションログで採点し、使った機能の種類では見ないと書いていた」と書く。Tekton にある参加者ガイドの33行と34行では、セッションログから採るのは自律(Autonomy)だけで、統率(Orchestration)は「Judged from the submitted brief, rubric, and any workflow scripts (not from which features were used)」となっている。compare の原文の18行、apply の原文の85行と88行もこのとおりに書いている。要約は2つを1つにまとめて、統率までセッションログで採ったことにしている。
