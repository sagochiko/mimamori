### cc8a2c2 会話が短くなったときに最新を見せる

`~/develop/mimamori/.claude/worktrees/issue-86-ai-chat-look/ios/App/Views/ProtectedHomeView.swift` 111〜119行の `onScrollGeometryChange` と 225〜235行の `ConversationViewport`。

Apple の文書は HTML が端末側で描かれて本文が取れなかったので、描画の元の JSON(`developer.apple.com/tutorials/data/documentation/swiftui/...`)を curl で読んだ。`visibleRect` は「content offset、content insets、container size から計算される」、`bounds` は「visible rect と違い、content insets の内側」、`contentInsets` は「content size に足すとスクロールできる全体」、`onScrollGeometryChange` の action は「変換した値が変わるたびに呼ばれる」、iOS 18.0 から(アプリの deploymentTarget は `ios/project.yml` で 26.0)。もう1つ、「下に ScrollView が複数あると最初の1つだけが closure を呼び、runtime issue が出る」とある。この modifier は会話の ScrollView 自身に付いていて、その中に ScrollView は無い(ChatTurn、Bubble、LiveView だけ)。上の帯の ScrollView と欄の UITextView は VStack の兄弟で外側なので当たらない。

「最後まで見えている」の判定 `visibleRect.maxY >= contentSize.height - 1` は、この ScrollView に縦の content inset が無いことが前提。会話は VStack の真ん中の行で、帯が出るときもキーボードが出るときも VStack の配置が変わって ScrollView の `containerSize` が縮む(inset が付くのではない)ので、前提は成り立つ。帯の場合は親が撮った画像で確かめ済み、キーボードの場合は同じ仕組みからの推論で、撮ってはいない。1pt の余裕は 3x の端数の配置に対して十分で、下に引っ張り過ぎたときは `maxY` が `contentSize.height` を超えるので true のまま。`scrollTo` は offset を変えるだけで高さは変えないので、高さの変化を条件にした guard で呼び直しの輪にならない。

相談の流れをコードで追った。送ると `.thinking` で `followsConsult` が true になり、`reveal` が一番下(`liveID`)へ寄せる。このあいだ高さが変わっても新しい guard は `!followsConsult` で何もしない。答えが来ると `reveal` が最後の発言の先頭(1行目)へ寄せる。`handoff` が false ならその場で `followsConsult` が false になり、以後の縮みは「終わりが見えていたら終わりを見せる」の規則に任される。長い答えなら終わりは見えていないので動かず、1行目が見える動きは壊れていない。

1つだけ閉じきれていない窓がある。`handoff` が true のとき、`.onChange(of: notices)` が `reveal`(1行目へ)を呼んだ直後に `followsConsult` を false にする。SwiftUI が高さの縮みをそのあとに報告し、古い高さでは答えの終わりまで見えていて新しい高さでは見えないなら、新しい callback が終わりへ寄せて1行目の `reveal` を上書きする。標準の大きさの長い答えでは `old.showsEnd` が false なので起きない。起きうるのは、古い高さに収まって新しい高さに収まらない答えで、dev-log にある accessibility-large の「4行目から下が隠れた」はまさにその幅。そこでは1行目ではなく終わりが見える形になる。承認を変える理由にはしない(答えの勧める行動は終わりにあり、ずらせば読め、VoiceOver は全部読み、直す前は終わりが隠れていた)。ただ親の画像は「最新の位置で開く」場面で、相談の途中は撮っていないので、検証役に accessibility-large で `-mimamori-stub-heard` にニセ警察の文を渡して相談を流し、帯が出たあとに答えのどの行が見えているかを撮ってもらい、1行目と終わりのどちらを望むかを親が決めるとよい。
