### 42-2 直すべき。stub の確かめの根拠に書いた「Debug なら 8」が実測と違う

[`.claude/skills/mm-release/SKILL.md`](.claude/skills/mm-release/SKILL.md) の54行目は `strings -a "$APP/Mimamori"` を数える。57行目は「A Debug build of the same check prints 8, so 0 means the stub is gone, not that the check is broken」と書いている。Xcode 27.1 で Debug をビルドすると、コードは `Mimamori.debug.dylib` に入り、同じ確かめは `Mimamori` に当てると 0、`Mimamori.debug.dylib` に当てると 8 になった(上の検証)。Release には debug dylib が無いので、Release で 0 になるという結論自体はたぶん正しい(推測。Release のアーカイブは作っていない)。ただ、「確かめが壊れていないことの証拠」に書いた文が誤りなので、確かめの仕組みが壊れても気づけない。直し方は2つある。`grep -rc` で `.app` 全体に当てる(`strings -a` を `find "$APP" -type f` の全ファイルに流す)か、根拠の文を「Debug では `Mimamori.debug.dylib` に当てると 8」に直し、Release の `$APP` に `*.debug.dylib` が無いことも同じ手順で確かめる。

### 42-3 軽い。`git switch main` が本体の木のブランチを替える
