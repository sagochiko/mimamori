## 基準ごとの一番弱い証拠

### インパクト(7点)

一番弱い証拠は、ハッカソンのあとも使い続ける根拠だ。[`docs/judging.md`](~/develop/mimamori/docs/judging.md) の細目「ハッカソン後も誰がどんな場面で使い続けるか」は、自分たちの表でも「未」のままだ。[`docs/mother-feedback.md`](~/develop/mimamori/docs/mother-feedback.md) の記録は2026年11月7日の1件だけで、直したあとに母が困らなくなったかは「まだ見ていない」と書いてある。審査員は README の「What her use changed」の最後の段落と、この記録の最後の段落を見る。README 冒頭の「Today only people with a tech-savvy relative close by get this kind of protection」も、根拠が示されていない。

点を一番上げる変更は2つある。2026年11月8日の撮影(試験用のニセ警察の電話)で母がどう動いたかを、[`docs/mother-feedback.md`](~/develop/mimamori/docs/mother-feedback.md) と README の「What her use changed」に日付つきで足す。あわせて、提出後も母と妹と作者の家族で使い続けること、TestFlight のビルドの期限を誰がどう延ばすかを、README に3文ほどで書く。

一番弱い証拠は、Managed Agents の結果が家族に届く最後の一歩を見ていないことだ。README の「Tried on the author's iPhone」と [`docs/submission.md`](~/develop/mimamori/docs/submission.md) の「Claude Managed Agents」には、「the line on a family card was not looked at」「家族のカードの1行は見ていない」とある。本番で動いたのも1回だけだ。

点を一番上げる変更は、家族役のシミュレータ(本番の家族に入っていない試験の家族)で、Safari の試しのページから届いたカードの「<site name>の注意喚起」の1行を一度見ることだ。見たら、README の該当行と #187 に記録する。動画では、撮影の差し込みのついでに、この1行が映るカードを `familyCard` の場面に入れる。
