## 確かめて問題なかったこと

- `ios/Core/Sources/MimamoriCore/ExtensionGuide.swift` の Safari の手順に、写真なしの6段目「「アクセス権」の下に出る行を押して「許可」を選ぶ」が足された。これで、5段目でスイッチをオンにしたあと、サイトへのアクセスを許可するところまで母が進める。
- 「アクセス権」は、撮った `06-safari-guide-bottom.png` に写っている見出しで、文言が合っている。その下の行の名前は撮れていないので引用していない。「許可」も写真には写っていないが、Issue #287 の指定と同じ言葉で、選ぶ値を指しているだけなので、行の名前を記憶で書いたことにはならない。母の実機で行の名前を確かめる作業は、もともと残すことになっている。
- 写真の無い段は、`ExtensionGuideView` で文がそのまま読み上げられる。写真が無いので `accessibilityHidden` は false になる。画像の名前が `nil` なので、`imagesExist` の対象からも外れる。
- `ios/Core/Tests/MimamoriCoreTests/ExtensionGuideTests.swift` の `safariSteps` は、6段の言葉を全部比べている。そのうえで、5段目までに画像があること、6段目に画像が無いことを確かめる。6段目を消したり言葉を変えたりすれば落ちる。
- `spokenLabel` は段の番号で引くだけなので、6段に増えても壊れない。
- 直しの差分は `ios/Core` の2つのファイルだけで、家族の画面とアセットには触れていない。
