## ハッカソンごとの説明

### Built with Opus 4.6（2026年2月）
Anthropic が初めて公式に開いた仮想ハッカソン。約500人が選ばれ、1人500ドルの API クレジットと1週間を得た。賞金は API クレジット10万ドル分。発表ページは6人の受賞者を選ぶと書きながら5件しか載せておらず、欠けた1件は確かめられない。発表ページの日付は2026年4月20日と出るが、受賞の発表自体は2月18日から2月20日ごろとする二次情報がある（公式で確認できたのは、上位6組の発表が2月18日という応募者の手元のルール写し、Hugging Face 上の dataset 内の文書だけ）。応募者数は「1万3000人」とする報道（NewsBytes）があるが、公式ページでは確認していない。ルールの写しには、デモで見せるものはすべてオープンソース、3分以内のデモ動画、公開 GitHub リポジトリが提出条件とある。そのため受賞作のリポジトリが公開されている件数が多いのは、提出条件の結果と読める（推測）。

### Built with Opus 4.7（2026年4月）
同じく Cerebral Valley と Anthropic の仮想ハッカソン。500人が選ばれた（Cerebral Valley のページでは応募者の枠が500人。「2万人超が応募」は二次報道）。発表ページの日付は2026年6月15日で、受賞者は6組。Cerebral Valley のギャラリーには288件の提出と9件の「Finalist」の表示があるが、ファイナリストの一覧は取れなかった。

### Claude Opus 4.8 Build Day（2026年6月13日）
サンフランシスコでの12時間の対面ハッカソン。1500人超が応募し310人が参加。上位3位だけを発表している。

### Forum Ventures x Anthropic（2025年9月12日）
ニューヨークで開かれた。Forum Ventures の告知ページに日付と「Anthropic の API と Claude Code のクレジットが賞品」とあるだけで、受賞者の公式発表は見つからなかった。Zenith の件は個人の投稿と二次情報（中国語の事例集、動画ページ）に基づくので、受賞作としては扱わず参考に留める。
