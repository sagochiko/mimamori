## 確かめて問題なかったこと

差分が手順1のとおりか。`git diff --stat origin/main...release-build-5` は次の2ファイル、3行だけだった。

```text

```

`~/develop/mimamori/ios/project.yml` の25行目が `CURRENT_PROJECT_VERSION: "4"` から `"5"` に、`~/develop/mimamori/ios/Mimamori.xcodeproj/project.pbxproj` の831行目と933行目が `CURRENT_PROJECT_VERSION = 4;` から `= 5;` に変わっている。手順1の「`project.yml` に1行、`.pbxproj` に2行」と一致する。

番号が origin/main の次の数か。origin/main の `ios/project.yml` は `"4"` で、先の版の PR は #76(3)と #120(4)なので、5 が次の数になる。ブランチの土台は `git merge-base origin/main release-build-5` が `1f7e82a` で `git rev-parse origin/main` と同じ。ブランチに入っているコミットは `f9329f0` の1つだけで、`origin/release-build-5` と PR #127 の `headRefOid` もどちらも `f9329f0ff14b6eee60ee852accce32382763ec1b`、PR のコミット数は1。レビューしたものと PR の中身は同じ。

コミットのメッセージ。題は `chore(ios): ビルド番号を 5 にする`、本文は「TestFlight に上げる版の番号を git の番号と一致させるため。」と `Co-Authored-By: Claude` で、手順1のコマンドの文面どおり。時刻や個人の情報は無い。

`.pbxproj` の2行がすべてのターゲットの番号として足りているか。

- 変わった2つの構成は `5102609AF36B79352E4D6852`(Debug)と `69746873BBE2AD2666308177`(Release)で、どちらも `EB930AFBB7A9A335371574F0 /* Build configuration list for PBXProject "Mimamori" */` に属するプロジェクト全体の設定。ターゲットごとの構成(Mimamori、MessageFilter、SafariExtension、ShareExtension、CallDirectory、MimamoriTests)には `CURRENT_PROJECT_VERSION` が無く、`grep -n CURRENT_PROJECT_VERSION` の当たりはその2行だけ。上書きするものは無い
- `~/develop/mimamori/ios/Config/Shared.xcconfig` にも `CURRENT_PROJECT_VERSION` は無く、`MIMAMORI_API_HOST` の1行だけ
- `ios/App/Info.plist`、`ios/MessageFilter/Info.plist`、`ios/SafariExtension/Info.plist`、`ios/CallDirectory/Info.plist`、`ios/ShareExtension/Info.plist` の5つとも `CFBundleVersion` が `$(CURRENT_PROJECT_VERSION)`、`CFBundleShortVersionString` が `$(MARKETING_VERSION)`。アプリと埋め込む拡張3つ(と埋め込まない ShareExtension)はすべてこの1か所を読む。`MimamoriTests` は `GENERATE_INFOPLIST_FILE = YES` でアーカイブには入らない
- `ios/ExportOptions.plist` は `manageAppVersionAndBuildNumber` が `false` のままなので、上げた版の番号は git の 5 のまま

`.pbxproj` が XcodeGen の出力そのものか。`ios/` を scratchpad に複製(`.build`、`DerivedData`、`.xcodeproj` を除く)して `/opt/homebrew/bin/xcodegen generate --spec <複製>/ios/project.yml --quiet` を流し、できた `project.pbxproj` をコミット済みのものと `diff` したところ `IDENTICAL`(差分なし)だった。手で直した跡は無い。複製は確かめたあと消した。リポジトリの作業ツリーは触っていない(`git status --short` は前からある `?? server/.claude/` だけ)。

PR の本文。本文を時刻(`HH:MM`、「N時N分」)、電話番号の形、メールアドレス、`gmail` の規則で grep して当たりは無し。日付は「前の日」という書き方だけで、時刻は書いていない。母や家族の名前、相談や SMS の中身も無い。本文にある `https://mimamori.sago3.workers.dev` は、origin/main の `~/develop/mimamori/ios/Config/Shared.xcconfig` 5行目(`MIMAMORI_API_HOST = mimamori.sago3.workers.dev`)と `docs/dev-log.md` に既にあり、新しく外に出る情報ではない。差分の文脈に出る `DEVELOPMENT_TEAM = CTK4XXPWH9` は `CLAUDE.md` が公開してよいとしているチームの ID。本文は `gh pr create` で書かれているので `guard-private.sh` の関門も通っている。「## レビュー」が「あとで足す」のままなのは、親がこの報告を受けて足す前提なので指摘にしない。
