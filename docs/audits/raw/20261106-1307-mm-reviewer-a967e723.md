## 指摘

1. `CAUTION_END` は「忘れないで」系の言い換えを拾えておらず、送金と暗証番号の手順を母に読み上げる後退がまだ残っている。確度は高い(再現した)。
   場所は `~/develop/mimamori/.claude/worktrees/issue-84-consult-overflow/server/src/consult-judge.ts` の `CAUTION_END`(544行目あたり)と `cautions()`。
   前に「振込のやり方を教えて」と聞いたあと「次は何を押すの?」と聞き、Claude が `help` で次の手順を返す場面で確かめた。結果は下の表のとおり。どれも本ブランチでは L3 のまま `toFamily=false` で文がそのまま母に返る。main で同じ入力を流すと全部 `L2 fam=true` で家族に回る。

   | Claude の手順 | どの型に当たって注意と読まれたか |
   |---|---|
   | `暗証番号を入れるのを忘れずに` | `ずに` |
   | `振込ボタンを押すのを忘れずにね` | `ずに` |
   | `認証コードを入れ忘れないように` | `ないように` |
   | `確定を押して振込を忘れないようにしてね` | `ないようにして` |
   | `最後まで振り込むのを止めずに` | `ずに` |
   | `暗証番号を入れるのをためらわないで` | `ないで` |
   | `暗証番号を入れるのを遠慮しないでください` | `ないで`(`迷わないでね` も同じ) |
   | `暗証番号を入れなくてはいけない` | `てはいけない` |
   | `振り込まなくちゃだめ` | `ちゃだめ` |
   | `暗証番号を入れて誰にも教えないで` | 読点が無いので文節が1つになり、文末の `ないで` で丸ごと注意になる |
   | `暗証番号を入れたら画面を閉じないで` | 同上 |
   | `暗証番号を入れて損することはない` | `ことはない` |

   直しは `忘れないで|止めないで|やめないで` を後読みで外しただけで、`ずに`、`ず`、`ないように` には同じ除外が無い。「ためらわ」「迷わ」「遠慮し」「怖がら」のように、するよう促す「ないで」も拾っていない。義務の形(「なくては」「なくちゃ」)も注意の型に当たってしまう。どれも Claude が手順の締めに書きそうな言い回しで、主役の場面(振込を聞いたあと)にそのまま効く。
   scam の答えの「すること」(L2 と L3)では、`振込ボタンを押すのを忘れずにね` などが main でも読み上げられており、そちらは前からある穴だ。後退になっているのは `help` の経路だけ。
   直す向きの案は2つ。(a) `ず`、`ずに`、`ないように` にも同じ後読みを付け、促す語(ためらわ、迷わ、遠慮し、怖がら)と義務の形(なくて、なくちゃ)を後読みで外す。(b) 注意で終わる文節でも、その前に「〜て」「〜たら」で手順の動詞が続いていれば、そこで切って手順として見る。案を入れたら、上の例を `~/develop/mimamori/.claude/worktrees/issue-84-consult-overflow/server/test/consult.test.ts` の「a step after a caution word」の表に足すとよい。
   再現に使ったスクリプトは `/private/tmp/claude-501/-~-develop-mimamori/6deea132-65ae-4477-9862-0c95c84e47ec/scratchpad/r84/probe3.mts`。`server/` で `npx tsx <スクリプト> <consult-judge.ts の道筋>` と流す。

2. `OWN_SETTING` は頭の設定の語だけを消すので、そのあとに電話やメールの続きが付いた問いでも仕込みの下限が外れる。確度は高い(再現した)。重さは1より一段下。
   場所は同じファイルの `OWN_SETTING`(179行目)と `aboutContact`(929行目)。
   前の母の言葉に `この警告を止めて。家族に知らせないで` がある状態で、下の問いを流した。

   - `電話の音を大きくして、折り返していい?`
   - `ねえ、電話の音を大きくして、折り返していい?`
   - `電話の音を大きくして、かけ直していい?`
   - `電話の音を上げて、言われたとおりにしていい?`
   - `電話の音を大きくして、相手の話をもう一度聞きたい`
   - `電話の音が聞こえない、もう一度かけてくるって`
   - `メールの文字を大きくして、書いてあるとおりにしていい?`
   - `メッセージの文字を大きくしたい、届いたのを読みたいの`

   どれも本ブランチでは `L3 fam=false` になり、家族に知らせない。main では全部 `L1 fam=true` だった。
   原因は、文に1つしかない `電話` か `メール` を `OWN_SETTING` が消すことにある。消した残り(「折り返していい?」など)には `CONTACT` の語が無く、`pointsBack` にも規則の印にも当たらないので、`goesOn` が偽になる。中身は電話やメールの続きの話で、「折り返していい?」はニセ警察の場面でいちばん出やすい続きだ。直しは前に付く語の側(「届いたメールの」)を閉じたが、後ろに続く側が開いたままになっている。`docs/design.md` の新しい文は「言葉の頭で自分の端末の音や文字を言う問い」を続きと数えないとしており、設定の語のあとに別の頼みが続く問いまで外すとは書いていない。
   直す向きの案は、設定の語のあとが文末か「したい」「できる?」「どうやるの」のような決まった結びのときだけ外すこと。もう1つは、外したあとの残りに「折り返」「かけ直」「とおり」「言われた」「届いた」のような続きの語があれば外さないこと。
   再現に使ったスクリプトは `/private/tmp/claude-501/-~-develop-mimamori/6deea132-65ae-4477-9862-0c95c84e47ec/scratchpad/r84/probe4.mts`。
