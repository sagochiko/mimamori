## 新しい指摘(深刻な順)

### 1. 中。API エラーの行も `"type":"assistant"` なので、Fable の窓が最初の要求で失敗しても「最初のターンが走った」と判定し、両方のセッションが朝まで止まる

何が起きるか。Fable の窓が開き、同意を通る(または出ない)。skill は走って `Base directory ...` の行が transcript に入る。最初の API の要求がクレジット切れや 4xx で落ちると、Claude Code はそのエラーを `"type":"assistant"` の行として transcript に書き、入力待ちで止まる。裏のループは brief の道筋、assistant の行、skill の印の3つが揃うので exit 0 を返し、古いセッションは6の「Stop here」に入る。新しい窓はエラーで止まったまま誰も動かさない。作者が一番避けたい形。

確かめ方。transcript で見た。`"isApiErrorMessage":true` の行は1本の transcript に1行あり、その行は `"type":"assistant"` を含む。その transcript では最初の assistant の行(34行目)より後(1225行目)だったので、この経路が実際に起きた記録は無い。形が同じことだけ確認した。

直し方の案。assistant の行のうち API エラーでないものを要求する。`grep -F '"type":"assistant"' "$f" | grep -vqF '"isApiErrorMessage":true'`。より強くするなら、`"type":"tool_use"` を含む assistant の行を要求する。どちらの起動の文も最初に brief か CONDITIONS.md を読むので本物の最初のターンには必ず tool_use がある(引き継ぎで起動された transcript では2つ目の assistant の行、35行目に入っていた)。opus の行にも同じ穴があるので同じ直し方でよい。

### 2. 中。`.before` の一覧が無いと、親の今のセッションの transcript が5秒以内に「来た」と判定される

同じファイルの 97行(`grep -qxF "$f" "$HOME/tmp/mimamori-handoff-$stamp.before" && continue`)。

何が起きるか。autopilot の親(Opus の主)がメインのチェックアウトで動いていると、親自身の transcript に brief の道筋(Write の呼び出し)、assistant の行、`/mm-autopilot` を打たれたときの skill の印の3つが全部入っている。これを除くのは `.before` の一覧だけ。`.before` が無いと `grep -qxF` は exit 2 を返し(確かめた)、`&& continue` が効かず、親の transcript がループの1周目で exit 0 を出す。古いセッションは窓が同意で止まっていても「Stop here」に入る。`.before` が無くなる経路は3つある。4と5が別の Bash の呼び出しで、`stamp` を手で打ち直すときに揺れる。4の `ls "$projects"/*.jsonl` が zsh でグロブに当たらずファイルを作らない(確かめた。Bash ツールは zsh 5.9 で、当たらないグロブは `ls` を失敗させ、リダイレクト先も作らない)。4の `ls` の前の行で止まって4を最後まで流していない。今動いている主も引き継ぎで起動されたもので(`pgrep -fl "mimamori-handoff-"` で、brief を引数に持つ claude のプロセスが1つ見えた)、親が走る場所はまさにこのフォルダになる。

### 3. 低。zsh の NOMATCH で、transcript が1本も無いフォルダだとループが即 exit 1 になる

何が起きるか。Bash ツールは zsh なので、`for` のグロブが1つも当たらないとスクリプト全体がその場で止まる(確かめた。`for f in /nonexistent/*.jsonl; do ...; done; echo after` で `after` が出ず exit 1)。メインのチェックアウトから一度もセッションを始めていない Mac では、ループが1周目で exit 1 を返し、親は「10分待った」と思って pkill に進む。この Mac では10本あるので今は起きない。

直し方の案。`for f in "$projects"/*.jsonl(N)` と `(N)` を付けるか、ループの先頭で `setopt nullglob`。
