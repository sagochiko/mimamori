### 1. 「あの、方法」「あの、件」が main より前を指さなくなり、設計の「残るのは3つある」の外に出る(確度は高い、再現した。重さは低い)

[`server/src/consult-judge.ts`](~/develop/mimamori/.claude/worktrees/issue-158-points-back-variants/server/src/consult-judge.ts) の `FILLERS` は、切れ目の前の `あの` を呼びかけとして落とす。そのため、指す語の `あの` と、そのあとの `方法`、`件`、`こと`、`やつ`、`操作` のあいだに読点があると、残りの `方法` だけでは前を指すと読めない。main では読点を消してから `あの方法` に当てていたので、前を指すと読んでいた。[`ios/Core/Sources/MimamoriCore/Chat.swift`](~/develop/mimamori/.claude/worktrees/issue-158-points-back-variants/ios/Core/Sources/MimamoriCore/Chat.swift) も同じ段取りなので、同じように読む。`あの、やり方` は残りの `やり方` だけで当たるので、前を指すままになっている。

```text
M - あの、件
M - あの、方法
M N あの、やり方
```

M は main で前を指すと読んだもの、N はこの PR で前を指すと読んだもの、`-` は前を指さないと読んだもの。

「あの、方法」と読点で区切って書くことはまず無いので、実害は小さい。ただ [`docs/design.md`](~/develop/mimamori/.claude/worktrees/issue-158-points-back-variants/docs/design.md) の「残るのは3つある」には入っていない。向きは前を指さない側(送らない側)で、設計が選んだ側と同じだ。直すなら、残る場合に1行足すか、例の一覧に `あの、方法` を前を指さない例として留めておくくらいで足りる。

### 2. 根の連なりが語に見える場合が切れ目の前に残る(確度は高い、再現した。重さは低い)

`あね、これってなに` は、`あ` と `ね` の連なり(「姉」を仮名で書いたもの)を呼びかけとして落とすので、前を指すと読む。main では前を指さないと読んでいた。こうなるのは、仮名の「あね」に読点を続けて書いたときだけだ。1回目の指摘の「ねこの〜」(切れ目なしで語の頭を飲み込む型)とは違い、切れ目を求めることで塞げる範囲の外にある。起きることはごく稀で、残しても困らない。

```text
- N あね、これってなに
```
