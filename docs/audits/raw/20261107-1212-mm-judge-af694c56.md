## 基準ごとの一番弱い証拠

一番弱いのは、ハッカソンのあとも母と家族が使い続けるという細目だ。[`~/develop/mimamori/docs/mother-feedback.md`](~/develop/mimamori/docs/mother-feedback.md) の「記録」の節は「2026年11月5日の時点では、母の iPhone にまだアプリが入っていない」で止まっている。README の「What her use changed」もコメントだけの空欄だ。実機で試した記録はどれも、作者の iPhone を母の役にしたものしか無い。

上げる一手は、2026年11月8日の撮影で母が実際に触った場面を、日付つきで1件だけ `docs/mother-feedback.md` に書くことだ。どこで止まり、手助けなしで何ができたかを書き、README の空欄にも1段落写す。文書なので、コードを止めた後でも書ける。

### デモ(6点)

一番弱いのは、デモ動画がまだ無いことだ。README の冒頭は `<!-- Demo video: link goes here. -->` のままになっている。それに次ぐのが審査員の入口の不確かさだ。#187 には、シミュレータで「体験」の SMS の「送る」を1回押しても画面が変わらず、2回目で結果が出たと書いてある。[`~/develop/mimamori/ios/App/Views/DemoView.swift`](~/develop/mimamori/ios/App/Views/DemoView.swift) の `send()`(197行目から)を読んだが、1回目を捨てるような状態の競り合いは見当たらなかった。キーボードが出ているときの最初のタップがキーボードを閉じるだけで終わっている可能性はあるが、これは推測で、コードからは決めきれない。TestFlight の招待の文はビルド9を指している。

上げる一手は、[`~/develop/mimamori/docs/design.md`](~/develop/mimamori/docs/design.md) の「デモの流れ(3分)」の順で動画を撮ることだ。最初の15秒に数字と母の言葉、続く45秒にニセ警察の場面を置き、README の冒頭にリンクを入れる。コードを止める前に作者の iPhone のビルド10で「体験」が出ること、「送る」が1回で効くことを確かめれば、なお良い。

### Claude の活用(8点)

一番弱いのは、開発で Claude Code をどれだけ使ったかを示す回数を、審査員が確かめられないことだ。[`~/develop/mimamori/docs/claude-usage.md`](~/develop/mimamori/docs/claude-usage.md) と README の「How Claude Code built it」が挙げる数、つまりレビュー役の起動170回、フックが止めた208回は、フックの記録から数えたものだ。その記録の `.claude/logs/` は `.gitignore` の18行目で外され、追跡されているファイルは0件だった。公開のリポジトリで裏付けがあるのは、`docs/audits/raw/` の原文、コミットの共著の行、PR の「レビュー」の節に限られる。作品の中の Claude にも穴がある。Managed Agents は [`~/develop/mimamori/server/src/agents.ts`](~/develop/mimamori/server/src/agents.ts) と試験はあるものの、README 自身が「no evidence line has been written by the real API」と書いている。

### 深さと実行力(8点)

一番弱いのは、精度の主な数字が dev だけで、合わせ込みの疑いを打ち消せていないことだ。[`~/develop/mimamori/eval/RESULTS.md`](~/develop/mimamori/eval/RESULTS.md) では、規則だけの見逃しが2026年11月7日の #21 で28.3%から8.3%、10.0%へ下がっている。README も、dev の見逃しを1件ずつ読みながら直した数字だと認めている。holdout の行はまだ無い(#213 は開いたまま)。細かい点では、`eval/RESULTS.md` の表と前書きに「08:44」「01:41」のような時刻が残っている。CLAUDE.md の「公開される記録には時刻を書かない」に反していて、リポジトリを読む審査員の目に入る。

上げる一手は、作者が鍵を置いて holdout を1回測ることだ(#213)。規則だけと規則と Claude の2行を `eval/RESULTS.md` に足し、README の `<!-- Holdout result ... -->` を埋める。dev より悪く出ても、そのまま載せたほうが深さの証拠として強い。
